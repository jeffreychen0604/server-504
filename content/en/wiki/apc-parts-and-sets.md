# APC Parts & Parts Set

> **Last verified:** 7 Aug 2026  
> **Source confidence:** High for current Parts Set and Gears-removal changes; medium for legacy unlock levels and old material tables.

Modified Vehicle **Parts** are a separate progression track from the vehicle's main Modify level and from APC chips.

## Parts Set

Official October 2025 patch notes added the **Parts Set** feature:

- all **6 parts** participate in the set system;
- upgrading the six parts to specified levels grants additional attribute bonuses;
- higher set milestones can unlock new Modified Vehicle skins.

Because the bonus depends on the six-part set, over-investing in only one part can delay a valuable set milestone. When exact set thresholds are added to this Wiki, they should be copied from the current Server 504 interface rather than from an old chart.

## Important resource change

The same official patch removed **Gears** from Modified Vehicle Parts upgrades and refunded old Gears previously spent on parts.

This makes early community tables that list Gears as a permanent part-upgrade requirement obsolete.

## Design Blueprints and Titanium Alloy

Older community data identifies **Titanium Alloy** and **Design Blueprints** as important APC/part progression materials. Dark War Survival Data describes Design Blueprint as an advanced-parts resource and lists Season Shop, Black Gold Shop and offers as historical sources.

Those items are still useful reference terms, but exact costs at modern part levels must be re-captured because the system caps and material rules have been expanded since the earliest tables were published.

## Current cap warning

An early 2025 APC chart listed much lower part and vehicle caps. Later official updates expanded vehicle Modify to **Lv.500**, introduced Parts Set, and then used **all parts Lv.66** as one possible Tactical Modification unlock condition.

Therefore:

- do not use old “parts max at 42” guidance as current;
- do not use old Gears costs for modern part upgrades;
- version every numeric part table.

## Upgrade planning

A practical progression approach is:

1. check the next Parts Set milestone across all six parts;
2. compare that milestone against a single-part upgrade;
3. preserve scarce advanced materials for meaningful thresholds;
4. align expensive upgrades with scoring events where relevant;
5. remember that all-parts development can also contribute toward Tactical Modification unlock.
