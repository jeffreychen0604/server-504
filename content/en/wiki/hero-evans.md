# Evans

> **Identity verified:** 7 Aug 2026  
> **Meta reviewed:** 7 Aug 2026  
> **Rarity:** S / Orange  
> **Faction:** Shooter  
> **Specialty:** Vehicle Transformation

Evans is a Shooter hero whose account value is closely tied to the **Modified Vehicle / APC progression economy**.

## Acquisition

Community data lists Evans as recruitable through the **Radio Station**.

## Skill structure

### Apocalypse Crossbow — Active Skill

Direct-damage Active Skill.

### Swift Strike — Normal Attack

Standard Normal Attack progression.

### Transformation Master — Progression Skill

Public data lists a progression path that includes:

- free Gears each day;
- additional daily Gears at higher stars;
- reduced Gear cost for Modified Vehicle upgrades;
- increased Modified Vehicle movement speed;
- increased Modified Vehicle skill damage at the highest listed breakpoint.

Because the APC/Modified Vehicle system is a permanent combat layer, Evans can remain strategically useful outside a main Shooter formation.

### High Morale — Exclusive Talent

Public data lists hero ATK +10%, DEF +10% and troop capacity +5%.

## Current usefulness

**Decision label: Progression utility / APC economy.**

Best-fit use cases:

- players still investing heavily into Modified Vehicle progression;
- Gear-constrained accounts;
- accounts using event timing for APC upgrades;
- secondary Shooter formation if combat investment is already present.
