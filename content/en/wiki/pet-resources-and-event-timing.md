# Pet Resources & Event Timing

> **Last verified:** 8 Aug 2026  
> **Confidence:** Official for event scoring integration; Server 504-observed for several current resource names; community-backed for some acquisition/use descriptions.

Pet resources now interact directly with weekly event scoring, so their value is partly determined by **when** they are consumed.

## Current Server 504 resource names to track

The current Server 504 operating schedule already identifies Pet Training resources including:

- Advanced Tactical Rations;
- Nutrient Potion;
- Potential Chips;
- Spec Ops Honor Medals;
- Training Protocols.

These names should be treated as current Server 504 evidence. The exact effect, per-use value and scoring value of each item still need current UI capture before the Wiki publishes a fixed numeric table.

## Official scoring integration

Version `1.250.650` added Pet-item missions to:

- **Survival Preparedness — Unit Training**;
- **Alliance Duel — Holistic Growth**.

Therefore Pet items should be included in the same save/spend discipline already used for Hero fragments, Wisdom Medals, Power Cores and Precision Parts.

## Server 504 timing note

The current Server 504 double-dip schedule includes a Friday Pet Training window at **12:00–15:59 server time** for the Pet resources listed above.

Treat this as a Server 504 operational schedule, not a universal game rule. Event rotation can change.

## Community resource labels

Recent community guides also use broader/generic labels such as:

- Pet Feed / Tactical Rations;
- Advanced Training Manual;
- Pet breakthrough materials;
- Medals of Honor.

Localization and guide terminology may not map one-to-one to the current Server 504 inventory labels. The Wiki therefore avoids asserting equivalence without screenshots.

## Recommended inventory policy

For each Pet material, eventually store:

| Field | Why it matters |
| --- | --- |
| exact in-game name | prevents localization confusion |
| icon screenshot | fastest verification |
| primary function | level / breakthrough / training / potential / rescue |
| source | event, shop, dispatch, package, etc. |
| Alliance Duel points | double-dip planning |
| Survival Preparedness points | double-dip planning |
| weekly purchase limit | economy planning |
| last verified | patch safety |

## Spending rule

Unless an immediate Agent unlock or combat breakpoint matters more, prefer spending Pet resources when they score in **two systems at once**.
