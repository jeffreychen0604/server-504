# Radar & Scouting

> **Last verified:** 8 Aug 2026  
> **Confidence:** High for current client behavior; community tables are used only for building-level context.

The Radar is the main world-map intelligence facility. It supports scouting and Radar-event activity, while upgrades improve scouting performance.

## What the Radar does

Community building data describes Radar upgrades as increasing **Scouting Speed** and Combat Power. The current client also uses Radar as an entry point for gathering-type events and Radar tasks.

Official patch history confirms several current behaviors:

- idle scouting troops are automatically selected when scouting;
- scouting troop information is displayed separately on the main screen;
- scout marches show both march and return time;
- Radar Lv.15 unlocks the **Quick Start** feature for all Radar event types;
- when a gathering Radar event uses `Apply gathering recommended lineup`, only the **unit amount** is adjusted; the hero lineup is not replaced.

## Radar specialists

Catherine & Rex are documented in the Hero Database as a Radar-oriented progression hero. Their value should be read separately from direct PvP power.

## Scouting in war

Being scouted is an information event, not direct damage. Current client settings include an **Alert Flash Effect** option controlling the screen-edge warning when being attacked or scouted.

The Wiki should not publish a fixed list of all information revealed at each Radar level until current Server 504 screenshots verify it, because scouting-detail thresholds can be patched independently from the building's Scouting Speed stat.
