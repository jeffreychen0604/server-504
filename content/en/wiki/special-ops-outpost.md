# Special Ops Outpost

> **Last verified:** 8 Aug 2026  
> **Confidence:** Official for unlock/building role; community-backed for detailed sub-feature behavior.

The **Special Ops Outpost** is the building that unlocks Dark War: Survival's Pet Agent system.

## Official unlock model

Version `1.250.650` states that players build the Special Ops Outpost **as the storyline indicates**. Once available, the building opens Pet Agent systems including:

- Rescue;
- training;
- growth.

The official patch notes do not publish a Watchtower prerequisite or fixed State-day requirement for the building. The Wiki therefore does **not** invent one.

## What players should expect inside

Community guides describe the Outpost as the hub for:

- managing unlocked Pet Agents;
- leveling and breakthrough progression;
- special training / attribute refinement;
- rescue/unlock chains;
- Shadow Calls-style dispatch activity.

Exact tab names can vary by localization and later patches.

## Why the building matters operationally

The Outpost links several otherwise separate systems:

**Pet level progression → unlock later Pet Agents → gain stronger passive stats/exclusive skills → spend Pet materials during Alliance Duel / Survival Preparedness scoring windows.**

This makes the Outpost a progression hub rather than a decorative building.

## What is not yet canonical

The following should be captured from Server 504 UI before the Wiki treats them as fixed:

- exact construction prerequisite;
- exact build cost/time;
- tab names in current English localization;
- rescue-task quantities;
- Agent-level unlock thresholds beyond those confirmed publicly;
- exact daily/weekly limits for related dispatches.

## Practical checklist

When the building first becomes available:

1. Build it immediately unless doing so would badly break a scheduled Construction scoring window.
2. Open each Pet Agent and inspect the next unlock requirement before spending rare materials.
3. Identify which Pet resources score in the current Alliance Duel / Survival Preparedness cycle.
4. Treat rescue progression and material consumption as two separate decisions.
