# Daily Utility Routine

> **Last verified:** 8 Aug 2026  
> **Scope:** Low-friction daily checklist for recurring free value  
> **Confidence:** HIGH for the official features named below; exact reward values remain version-sensitive

A useful daily routine should reduce missed free value without turning Dark War: Survival into an all-day notification loop.

## Short session checklist

### 1. Radio Station

- Claim the **free daily recruit**.
- Check the current recruitment pool before spending rare tickets.

### 2. Black Market

- Inspect the daily refresh.
- Buy only offers that solve a real bottleneck.
- Treat Ruby refreshes as optional spending, not a mandatory daily action.

### 3. Adventure / Exploration

- Claim accumulated Adventure rewards before the live UI shows the storage is full.
- Push stages when the next clear is efficient and improves long-term idle income.
- Check Gathering Ground Exploration attempts/tasks.

### 4. Supply Station / Energy

- Claim available free Energy before a world-activity block.
- Current patches allow low-Energy prompts to claim recovery directly without navigating back to the Supply Station.

### 5. Radar

Official patch history confirms **Quick Start unlocks at Radar Lv.15** and applies to all Radar-event types. Apple's official gameplay tips also state that upgrading Radar reduces the wait between scans.

Use Radar as a batch activity where possible rather than reopening the game for every single task.

### 6. Apocalypse Guide

For Shelter Lv.10+, check the **Apocalypse Guide** through Gathering Ground when planning upcoming major events. It is more valuable as a preparation tool than as another red dot to clear.

## Event-aware adjustment

The routine changes when an active event scores one of these actions.

For example:

- recruitment can be saved if ticket use will score later;
- Energy can be saved/claimed around zombie or world-action scoring;
- Exploration tasks can be timed if an event rewards them;
- Black Market purchases should not be forced merely to create event points unless the item itself has value.

## Two-session model

For most maintenance days, a practical pattern is:

**Session A** — collect overnight progress, free recruit, market, Energy, Radar/Exploration.  
**Session B** — claim accumulated rewards, requeue long actions and prepare resources for the next server-time event window.

This is a planning model, not a game rule.
