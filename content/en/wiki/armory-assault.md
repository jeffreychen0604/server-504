# Armory Assault

> **Last verified:** 8 Aug 2026  
> **Confidence:** Community-verified event rules. Server 504 allocation practice is intentionally excluded from this game-mechanics article.

Armory Assault is an alliance-vs-alliance event centered on controlling one of **8 Armories**.

## Registration

Current community reference states:

- alliance leader or R4 can register;
- an alliance can register for up to **2 Armories**;
- registration uses multiple time-slot selections;
- if multiple alliances contest the same Armory, scheduling is determined from overlapping selected time slots;
- holding an Armory in the previous round can trigger automatic registration for that same Armory in the next round;
- the event operates in a **4-round cycle**, after which Armory occupation is reset.

Because these rules are community-sourced rather than current official patch text, Server 504 should verify the registration screen whenever the cycle structure changes.

## Battle rules

Community data describes the battle as follows:

- alliances attack an Armory through rallies;
- defenders reinforce it;
- a battle can last up to **2 hours**;
- holding continuous control for **30 minutes** captures the Armory for the round;
- if no alliance completes a 30-minute continuous hold, the alliance controlling it when the battle ends wins the round.

## Participation restriction

Players who join the alliance only after registration closes may be ineligible for that Armory battle. This makes roster timing important before registration lock.

## Rewards

Each of the 8 Armories can provide a different reward category. Community documentation lists examples such as:

- speedups;
- Orange Hero Fragments;
- equipment-related materials;
- Boost Ores.

A critical distinction is that **reward assignments can rotate**. The physical Armory identity and its current reward should therefore be treated as separate fields in any Server 504 tracking table.

## Game mechanic vs Server 504 allocation

The game provides registration, battle and reward mechanics. Any voluntary agreement about which Server 504 alliance uses which Armory is a **server operational policy**, not a universal Armory Assault rule.
