# Events Overview

> **Last verified:** 7 Aug 2026  
> **Source confidence:** High for event names/current existence; medium for exact scoring because event rules are adjusted by patches.

Dark War: Survival progression is strongly event-driven. Many resources that can be spent at any time are more valuable when used during the matching event window.

## Alliance Duel

Alliance Duel is a recurring alliance competition built around themed scoring days. Common scoring categories include building, research, hero development, troop development and broader growth activities.

Recent official updates show that the scoring model continues to evolve. For example, Pet item consumption was added to the **Holistic Growth** theme in 2026.

### Practical rule

Do not assume an old Alliance Duel point table is permanent. Save major upgrade resources when possible, then verify the current event interface before spending.

## Survival Preparedness

Survival Preparedness is another recurring progression event with theme-based tasks and ranking rewards. Official 2026 patch notes added Pet item consumption to the **Unit Training** theme and also changed matchmaking so opponents can be drawn from the player's Alliance Duel League group with similar Watchtower levels.

## State of Supremacy / Capital conflict

State of Supremacy includes cross-state competition and capital warfare. Community event data describes capital control time as an important victory condition, with state leadership / president appointment tied to the result.

Exact scoring values and escort-point rules have been patched multiple times, so publish mechanics separately from point tables.

## Zombie Siege

Zombie Siege is an alliance-defense event where members prepare formations and reinforce shelters against waves. Official patches have expanded the maximum difficulty and improved defense controls.

## Bio-Mutant

Bio-Mutant is an alliance damage event. Community data identifies it as a recurring source of valuable materials such as Power Cores at higher damage milestones. Event placement and timing rules can change, so verify the current event panel.

## Other recurring and special events

The game also rotates many additional systems, including examples such as:

- Shadow Calls
- Dark Syndicate escort content
- Arena and Champion Duel
- Peak of Glory
- Black Gold Battlefield
- Fishing and seasonal mini-events
- Mutant Mines and season-specific PvP modes
- temporary celebration events

## Server 504 event-writing standard

Each event article should answer five questions:

1. **What is the objective?**
2. **When does it happen?** Use server time.
3. **What should players save beforehand?**
4. **What actions score or matter?**
5. **What should alliance leadership coordinate?**

Exact scoring charts should always carry a verification date.
