# Chip Factory

> **Last verified:** 7 Aug 2026  
> **Source confidence:** High for Chip Factory purpose and the official Chip System rollout; medium for community-documented crafting material mapping. No official personal Watchtower unlock level has been found.

The **Chip Factory** is the targeted-crafting side of the Modified Vehicle Chip System. Instead of relying only on random chip chests, it lets players use chip materials to craft chips for the APC.

## Where it fits

The developer introduced the Chip System as a feature to **craft and install chips** for Modified Vehicles. Community walkthroughs of the live system show **Chip Factory** as a dedicated option within the chip/vehicle interface once the Chip System is available on the account/server.

Public official patch notes describe the Chip System rollout by State/date but do **not** publish a separate personal Watchtower level for Chip Factory access. Therefore, the Server 504 Wiki should not invent a WT unlock requirement.

If a player has Chip Materials but cannot see Chip Factory, first verify that the account/server has the Chip System active and open the Modified Vehicle / chip interface. A screenshot of the locked or missing menu is the best evidence for documenting any additional personal prerequisite.

## Crafting purpose

Community system guides describe the Chip Factory as the deterministic alternative to random chests:

- **Common Chip Materials** are used for Purple-chip crafting;
- **Advanced Chip Materials** are used for Orange-chip crafting.

Because material quantities and recipes can be adjusted, exact costs should be captured from Server 504's current Chip Factory screen before being added to a permanent table.

## Chip structure documented by community guides

Current community walkthroughs consistently describe:

- three factions: Fighter, Rider and Shooter;
- four chip roles/types: Deployment, Assault, Suppression and Barrier;
- quality tiers including Green, Blue, Purple and Orange;
- star-up progression for higher-quality chips;
- faction switching / formation-specific chip setups.

These are useful reference categories, but exact skill values and resonance thresholds should be verified in-game before publishing numeric tables.

## Where crafting materials come from

Official patch notes confirm recurring Chip Material sources such as:

- 3rd, 6th and 9th Daily Alliance Duel point-tier chests;
- Chip-related events such as Chip Chrono;
- selected Mod Vehicle packs and event rewards.

Zombie Siege also awards Random Blue Chip Chests, which provides chips rather than only raw crafting materials.
