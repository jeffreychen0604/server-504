# Alliance Tech

> **Last verified:** 8 Aug 2026  
> **Confidence:** High for system purpose; exact tree and numerical bonuses still require current in-game capture.

Alliance Tech is a shared progression tree funded by member donations. Unlike personal Research Center technology, Alliance Tech benefits the alliance collectively.

## What it does

Current community guides consistently describe Alliance Tech as covering two broad categories:

- **development bonuses** — construction/research efficiency and related account-growth effects;
- **combat bonuses** — troop attack/defense and other military improvements.

Because the exact technology names, maximum levels and bonus values can change, the Wiki does not yet publish a full numeric tree.

## Contribution loop

The stable player routine is:

1. open Alliance Tech;
2. donate to the alliance's current priority technology;
3. receive the associated alliance contribution/currency where applicable;
4. let alliance leadership coordinate focus so donations are not scattered across low-priority branches.

## Why focused donations matter

Alliance Tech is a shared resource pool. Ten members donating into ten unrelated branches can produce less immediate value than the same donations completing one high-impact technology first.

This is a **game-system observation**, not a Server 504 governance rule. Which technology should be prioritized at any given time belongs to alliance leadership and can change with season, event and roster needs.
