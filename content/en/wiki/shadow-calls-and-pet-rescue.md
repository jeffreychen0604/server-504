# Shadow Calls & Pet Rescue

> **Last verified:** 8 Aug 2026  
> **Confidence:** Official for Pet Agent Rescue as a system and Regulus rescue gate; community-backed for Shadow Calls ↔ Pet resource farming behavior.

Pet Agent progression includes a **Rescue** layer and, according to current community guides, a dispatch/economy loop through **Shadow Calls**.

## Pet Agent Rescue

Official Pet Agent launch notes explicitly list **Pet Agent Rescue** as one of the systems unlocked through the Special Ops Outpost.

The latest official Regulus patch gives a concrete example of how Rescue can gate a Pet Agent:

- first reach **Titan Lv.50**;
- then complete the required rescue tasks;
- Regulus becomes unlockable.

This suggests that Pet progression is not only a material/level grind: later Agents may also require a rescue-task stage.

## Shadow Calls

A current community Pet guide identifies Shadow Calls dispatches as a recurring source of Pet progression materials, including experience/growth items, breakthrough-related materials and badge-type rewards.

It also reports mission tags such as:

- Logistics;
- Combat;
- Tech.

Matching an Agent to the requested mission archetype is reported to improve the chance of a better dispatch result.

Because exact reward tables and success-rate formulas are not official public data, they remain `COMMUNITY / VERIFY SERVER 504`.

## Practical dispatch rule

1. Keep dispatch slots active whenever possible.
2. Match Agent tags/archetypes to mission requirements when the UI offers that distinction.
3. Prefer scarce Pet-growth resources over generic resources when reward value is otherwise comparable.
4. Do not spend rare Pet items immediately after collecting them if an Alliance Duel / Survival Preparedness double-dip window is near.

## Do not confuse systems

`Shadow Calls` existed before Pet Agents and has its own broader reward mechanics. The Wiki therefore does **not** claim every Shadow Calls task is a Pet task. Instead, current community evidence indicates it has become one useful acquisition channel for Pet progression.
