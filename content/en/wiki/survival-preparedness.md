# Survival Preparedness

> **Last verified:** 7 Aug 2026  
> **Source confidence:** High for current matchmaking and Pet-item changes; medium for exact task-point tables because scoring can be patched.

**Survival Preparedness** is a recurring progression event built around rotating task themes. It overlaps heavily with Alliance Duel, which makes resource timing especially important.

## Event model

Community event data describes Survival Preparedness as a multi-day event with time-windowed themes such as:

- Shelter Expansion;
- Hero Trial;
- Unit Training;
- Elimination Program;
- Modification Contest;
- Equipment-focused growth;
- mixed Arms Expert-style tasks.

Different themes reward different upgrade materials and activities, so the strongest strategy is usually to prepare resources before the matching window opens.

## Current matchmaking

Official December 2025 patch notes changed matchmaking:

- previously, opponents were selected from the player's current State with similar Watchtower levels;
- now, opponents are selected from the player's **Alliance Duel League group**, while still considering similar Watchtower levels;
- ranking rewards were increased at the same time.

This means Survival Preparedness should not be treated as purely an internal-State leaderboard anymore.

## Pet Agent integration

Official June 2026 patch notes added a new mission to the **Unit Training** theme: consuming Pet items can now earn points.

This is a good example of why fixed 2025 scoring charts cannot be copied unchanged into the current Wiki.

The exact active task list shown in-game is the authoritative source for that event cycle.

## Double-dip principle

The key optimization concept is **double dipping**: perform an upgrade when it scores in more than one active event at the same time.

Examples can include:

- construction during a matching Survival Preparedness window and Alliance Duel construction theme;
- hero fragments during overlapping hero-growth windows;
- troop promotion when both events reward training;
- equipment or APC resources when matching themes overlap.

The actual overlap schedule is server- and cycle-dependent, so the Wiki should teach the principle rather than publish a permanent clock table.

## What to save

Useful reserves include:

- Precision Parts;
- Wisdom Medals;
- hero fragments;
- Power Cores;
- Hero Equipment Lucky Chests;
- Titanium Alloy and Design Blueprints;
- troop training speedups;
- construction/research speedups;
- Pet Agent resources after checking current task eligibility.

## Practical workflow

1. Check the upcoming theme before reset.
2. Compare it against the current Alliance Duel day.
3. Hold resources that can score twice.
4. Use PvE tasks such as zombies, Boomers or Radar when a material-spending theme is not efficient.
5. Avoid spending a scarce item simply because it scores if doing so damages long-term progression.
