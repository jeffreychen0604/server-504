# Troop Tier Progression

> **Last verified:** 7 Aug 2026  
> **Source confidence:** Medium. Public Dark War: Survival references currently conflict on several exact unlock levels.

Troop power scales heavily with troop tier, but the Wiki should not publish a false sense of precision when external tables disagree.

## Stable mechanic

Troop progression is gated by a combination of:

- Watchtower progression;
- the relevant Fighter, Rider or Shooter Camp level;
- Battle / faction research requirements;
- later Industrial progression.

Upgrading only one of these systems can leave the next troop tier unavailable.

## Current source conflict

One detailed progression table lists the following Watchtower milestone pattern:

| Troop tier | Community progression table |
| --- | ---: |
| T1 | WT3 |
| T2 | WT6 |
| T3 | WT9 |
| T4 | WT12 |
| T5 | WT15 |
| T6 | WT18 |
| T7 | WT21 |
| T8 | WT24 |
| T9 | WT27 |
| T10 | WT30 |

However, another page on the same community site claims earlier milestones such as T5 near WT11, T8 near WT22 and T10 near WT28. These two statements cannot both represent the same current unlock rules.

## Independent sanity check

Historical player account listings provide weak but useful corroboration for the later milestone pattern:

- WT25 accounts have been advertised with T8 troops;
- WT28 accounts have been advertised with T9 troops;
- WT29 accounts have been advertised with T9 troops;
- WT30 / Industrial accounts commonly advertise T10 troops.

These listings are not authoritative game documentation, but they make the **WT24 / WT27 / WT30** pattern more plausible than the earlier-unlock claims.

## What the Wiki should say today

Until Server 504 captures the actual unlock screen, treat the table above as a **community reference**, not a guaranteed current rule.

For practical planning:

1. keep the main faction camp close to the Watchtower cap;
2. keep Battle/faction research moving in parallel;
3. before spending speedups for a troop-tier push, open the next troop entry in the camp and check its exact requirements;
4. screenshot the requirement screen so the Server 504 Wiki can replace community assumptions with in-game evidence.

## Industrial troops

After normal T10 progression, Industrial upgrades add another late-game power layer through Industrial Watchtower and faction-camp development. Exact Industrial troop unlocks should be documented separately because they depend on the current Industrial progression tree rather than the normal WT1–30 pattern.
