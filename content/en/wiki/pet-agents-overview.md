# Pet Agents — Overview

> **Last verified:** 8 Aug 2026  
> **Confidence:** Official for system existence, unlock building, event integration and Regulus release conditions; community-backed for detailed progression strategy.

Pet Agents are a permanent growth system accessed through the **Special Ops Outpost**. The system was officially introduced in version `1.250.650` on 13 Jun 2026.

## What the system does

Official patch notes confirm that Pet Agents provide:

- Pet Agent Rescue;
- training and growth;
- broad account/stat bonuses;
- powerful exclusive skills.

The important design point is that Pet Agents are **not a side collectible**. Their growth materials are now directly tied into recurring scoring systems.

## Event integration

Officially confirmed:

- **Survival Preparedness — Unit Training:** consuming Pet items can score points;
- **Alliance Duel — Holistic Growth:** consuming Pet items can score points.

For Server 504 planning this means Pet materials should be treated like Hero fragments, Power Cores and other timed progression resources: do not spend automatically if a double-dip window is close.

## Passive-account value

Community testing describes Pet Agent stats as persistent background bonuses rather than APC passengers. Examples reported by current 2026 guides include development stats such as building/research speed and combat stats such as Total Army ATK/HP.

Because this detail comes from community testing rather than an official formula sheet, exact attribute pools and roll ranges remain version-sensitive.

## Current top-end direction

The latest official Pet Agent announced in version `1.250.656` is **Regulus**, an S-tier Agent.

Official unlock condition:

1. raise **Titan to Lv.50**;
2. complete the Regulus rescue tasks.

Regulus's exclusive skill **King's Decree** temporarily increases Troop ATK.

## Server 504 operating rule

When deciding whether to consume Pet resources, check three things first:

1. Is Alliance Duel Holistic Growth active or approaching?
2. Is Survival Preparedness Unit Training active or approaching?
3. Does the Pet upgrade unlock a meaningful Agent/skill breakpoint immediately?

If the answer to 1 or 2 is yes and there is no urgent breakpoint, saving is usually more efficient than blind spending.
