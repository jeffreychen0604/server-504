# Formations & Unit Presets

> **Last verified:** 7 Aug 2026  
> **Source confidence:** High for current preset/defense features; medium for community formation-bonus math.

Formation building in Dark War: Survival should align four layers: **hero faction, troop faction, research and APC/chip setup**.

## Fighter / Rider / Shooter

The game supports three combat factions:

- Fighter
- Rider
- Shooter

The established counter triangle is:

- Fighter counters Rider;
- Rider counters Shooter;
- Shooter counters Fighter.

This means “highest CP” is not always the best answer when a faction counter or formation-wide passive is involved.

## Official Recommended presets

Official October 2025 patch notes added a **Recommended** button to the troop interface with four one-tap schemes:

- **CP First**
- **Fighter First**
- **Shooter First**
- **Rider First**

These are useful as a fast baseline, but they do not replace manual formation planning for PvP, rallies or specialized events.

## Defense Presets

The same update introduced **Defense Preset** at the City Gate.

Players can pre-set multiple defense squads. If heroes in the first preset are already deployed elsewhere, the game uses the next-priority preset. If no secondary preset exists, the strongest available heroes are auto-deployed.

This makes defense planning important before large wars: a strong first lineup is not useful if its heroes are committed to another march when the shelter is hit.

## Same-faction concentration

Community testing consistently recommends concentrating a main formation around one troop faction because the same investment can then be multiplied by:

- faction research;
- hero faction passives;
- faction counter effects;
- APC/chip bonuses;
- formation/faction bonuses shown in combat reports.

Some community guides report a same-faction formation bonus at specific hero counts. Because exact bonus values can be patched and are visible in reports, Server 504 Wiki should verify the current value in-game before publishing it as a permanent number.

## Chip-aware formations

Official Chip System notes state that City Gate defense formations can intelligently match chip setups based on **unit numbers and unit types**. Later UI updates also added faction indicators to chip icons.

Practical consequence: changing a formation's troop faction without checking its active chip setup can leave combat power on the table.

## Recommended planning workflow

1. Pick the target: world PvP, rally, defense, Adventure or event boss.
2. Check enemy faction if known.
3. Choose troop faction and hero core.
4. Confirm faction research supports that troop type.
5. Confirm APC/chip setup matches the formation.
6. Save separate Defense Presets for situations where the main march is away.
7. Compare battle reports after testing rather than trusting displayed CP alone.
