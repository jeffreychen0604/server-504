# Season 4 — Sealed Island

> **Server 504 naming:** Season 4 · Sealed Island  
> **Last verified:** 7 Aug 2026  
> **Source confidence:** High for season naming within the DWSI season directory and for officially patched Sealed Island systems; medium for community strategy details.

Sealed Island is the current seasonal framework used by Server 504. Community reference hub DWSI lists **Sealed Island under Season 4**, matching Server 504's in-game season context.

## Core seasonal systems

Sealed Island introduces a set of temporary progression mechanics built around Oni-themed enemies, Miasma/Virus Resistance and seasonal buildings.

### Miasma / Virus Resistance

Seasonal combat can require sufficient **Virus Resistance**. Fighting while under the recommended resistance can reduce efficiency and expose the shelter to Miasma-related penalties.

Community guides identify the **Oni Seal Hall** as the key resistance-building structure. Because resistance gates seasonal enemies and territory progression, it should generally be treated as a progression priority rather than a cosmetic building.

### Seasonal resources

Community references consistently describe two important building resources:

- **Stone** — used in seasonal building progression.
- **Quartz** — produced/used through seasonal structures and required for advanced upgrades.

Exact costs should be verified from Server 504's current in-game season interface before publishing a numeric table.

## Blood Moon Shroud

Official patch notes confirm **Blood Moon Shroud** as a Sealed Island event and reference Blood Moon variants of seasonal enemies.

Examples explicitly named in official patch history include:

- **Rotting Onis**
- **Booze Brutes**
- Blood Moon versions of both enemy types
- **Oni King**

The developers have adjusted recommended CP, Viral Resistance and Oni King HP during the season, demonstrating that hard combat thresholds can change during a live season.

## Oni King

Official patch notes state that Oni King HP was increased after some servers defeated it too quickly for all survivors to participate. This is another reason the Wiki should document encounter mechanics separately from temporary balance numbers.

## Sacred Tree Blessing and seasonal events

Community sources document additional Sealed Island activities such as:

- **Sacred Tree Blessing**
- **Float Parade**
- seasonal mini-events
- Miasma-related achievements and burst phases

These are useful as event articles, but reward tables should be verified against Server 504 because schedules and reward pools may change between server clusters or patches.

## Server 504 operational note

Some third-party websites label Sealed Island with a different season number. DWSI's organized Dark War: Survival season directory places **Sealed Island in Season 4**, and Server 504's current in-game context also uses Season 4. The Server 504 Wiki therefore follows the Server 504/DWSI numbering rather than importing numbering from unrelated or differently sequenced guides.
