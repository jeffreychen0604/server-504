# Alliance Duel

> **Last verified:** 7 Aug 2026  
> **Source confidence:** High for the weekly structure and current official changes; medium for exact scoring values because the task table has changed over time.

**Alliance Duel** is a week-long alliance-vs-alliance competition. Each day uses a different scoring theme, so the event rewards planning more than uncontrolled daily spending.

## Core structure

Community event data consistently describes the event as a daily-theme competition between two alliances. Each day awards points for specific actions such as construction, research, hero development, troop development, APC growth or PvP. The alliance with the higher daily score wins that day, while the overall duel is settled across the week.

Current official patch notes also confirm that in the Conquest/State Duel context, **Day 6 is Enemy Buster Day**.

## Why resource timing matters

Many Alliance Duel actions consume materials that are also useful elsewhere. Common examples include:

- construction and research speedups;
- Wisdom Medals;
- hero fragments;
- Exclusive Equipment fragments;
- Power Cores;
- Hero Equipment Lucky Chests;
- Precision Parts;
- APC / Modified Vehicle materials;
- troop training and promotion resources;
- selected Pet Agent items.

A strong account does not necessarily score by spending more; it scores by spending at the correct time.

## Current version-sensitive changes

Official 2026 patch notes added a new mission to the **Holistic Growth** theme that awards points for consuming Pet items.

Official season notes also confirm that Alliance Duel Day 6 can become **Enemy Buster Day** during Conquest/State Duel content.

Because scoring tables evolve, an old point chart should be treated as a historical reference only.

## Enemy Buster

Enemy Buster is the PvP-focused day. Practical preparation usually includes:

- Advanced Teleporters;
- shields for players who are not participating in combat;
- hospital capacity and healing resources;
- clearly assigned rally and reinforcement roles;
- target discipline to avoid wasting troops;
- awareness of cross-state teleport rules.

Official 2026 changes allow direct cross-state relocation by selecting a location on the opponent State map during supported cross-state events such as Alliance Duel Enemy Buster.

## Duel research and long-term value

Community strategy discussion consistently treats **Duel research** as a high-value long-term investment because it improves Alliance Duel efficiency and rewards. Exact tech effects should be verified in the current Research Center before publishing a fixed table.

## What to save

A practical rolling reserve is:

| Category | Typical materials to reserve |
| --- | --- |
| Construction | speedups, Precision Parts, structure resources |
| Research | speedups, Wisdom Medals |
| Heroes | recruitment tickets, hero fragments, Exclusive Equipment fragments |
| Equipment | Power Cores, Hero Equipment Lucky Chests |
| APC | Titanium Alloy, Design Blueprints, chips / chip materials |
| Troops | training speedups, promotion-ready units |
| PvP | teleporters, healing capacity, shields |

The current event interface always has priority over this table.

## Alliance coordination

Leadership should publish a short weekly plan covering:

1. which days the alliance intends to push hard;
2. which scarce materials members should hold;
3. minimum target milestones if the alliance uses them;
4. Enemy Buster participation and shield policy;
5. whether seasonal or server events overlap the same resources.

The Game Wiki should explain the event mechanics. Server 504-specific timing, saving rules and war policy belong in the Operational Codex or current server notice.
