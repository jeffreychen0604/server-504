# Event & Premium Currencies

> **Last verified:** 7 Aug 2026  
> **Scope:** Temporary exchange currencies and paid virtual currency.  
> **Rule:** Event currencies can disappear with the event; spend/expiry rules must be verified in the current event UI.

Dark War: Survival regularly introduces temporary currencies for seasonal and limited-time events. These should not be stored in the Wiki as if they were permanent account currencies.

## Honor Points

**Status: Official current-system currency.**

Official update notes state that currencies from State of Supremacy, Capital Clash and Black Gold Battlefield are replaced by **Honor Points** as the unified Honor Shop system rolls out.

Legacy conversion rules announced by the developer:

- 1 Capital Glory Badge → 40 Honor Points;
- 1 Black Gold Coin → 2 Honor Points.

## Personal Points / Alliance currency

**Status: Current community-verified.**

Used in the Alliance Shop. Recent 2026 guides list Alliance Tech donations, Alliance Help and alliance event activity as repeatable sources.

Community language sometimes calls these Alliance Coins/Alliance Points; the Wiki prefers the current UI wording when a Server 504 screenshot is available.

## Mechanical Components

**Status: Community-documented event currency.**

Industrial Surge uses Mechanical Components as an exchange material. Community data describes obtaining them from Radar events and Steel Zombies, then exchanging them for **Precision Parts** and other Industrial materials.

## Magatama

**Status: Sealed Island / Blood Moon community reference — verify Server 504 UI.**

Community Sealed Island guides describe Magatama as a limited Blood Moon exchange currency obtained from Blood Moon enemies such as Rotting Oni / Booze Brute variants and spent in a temporary exchange shop.

Public guides disagree on season numbering and can differ on shop naming, costs, weekly limits and whether unused Magatama expires. Server 504's current event UI is authoritative for all of those fields.

Do not publish a permanent Magatama cost table until captured in-game.

## Shell Coins

**Status: Official limited-time event currency.**

The Jul 2026 official App Store notes introduced the **Summer Snap** event and explicitly state that participation awards **Shell Coins**, exchangeable for rare items, exclusive skins and other rewards.

This is a good example of why event currencies belong in a versioned index rather than the permanent economy model.

## Dawn Badges

**Status: Official paid virtual currency.**

The official Dark War payment center defines Dawn Badges as an in-game virtual item used to exchange for:

- packs;
- weekly passes;
- monthly passes;
- battle passes.

Important official rule: purchasing Dawn Badges on the website **does not itself grant VIP Points**. VIP Points are credited when Dawn Badges are exchanged for qualifying packs in-game.

Dawn Badges cannot be transferred between UIDs.

## Rubies / premium in-game currency

Rubies remain a broad in-game premium currency used across convenience, attempts, refreshes and other purchases. Exact recommended Ruby spending changes with progression and event schedule, so the Wiki does not maintain a single permanent “best Ruby use” table.
