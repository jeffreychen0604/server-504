# World Map & State Systems

> **Last verified:** 8 Aug 2026  
> **Scope:** World-map movement, shelter defense, cross-state interaction and State-level systems.  
> **Rule:** Season-specific mechanics are versioned and are not treated as permanent global rules.

Dark War: Survival's world map connects several systems that are easy to confuse if read separately: scouting, teleportation, shelter defense, durability, gathering, special map structures, cross-state combat and State administration.

## Core map layers

### Movement & information

- Radar and scouting provide map intelligence.
- March queues are used for attacks, rallies, gathering and scouting.
- Auto Return behavior differs by activity; current official notes say it is enabled by default for solo-zombie attacks and disabled by default for other march scenarios.

### Shelter defense

- Peace Shields protect shelters from hostile interaction while active.
- The City Gate manages defense squads.
- Current official client behavior supports multiple Defense Presets.
- Shelter durability and burning matter independently from troop casualties.

### Cross-state warfare

Current official rules allow direct destination selection during supported cross-state events rather than random relocation. The opposing State map can be tapped directly during events such as State of Supremacy and Alliance Duel Enemy Buster.

The former Capital Teleporter is being phased out: Advanced Teleporters can now be used in the Lost Lands, while remaining Capital Teleporters are consumed first if a player still owns them.

### Special map zones

Some structures create unusual combat conditions. Trade Post / Merchant Guild dark zones, Capital Lost Lands, Mutant Mines and season maps can all alter attack, teleport, mortality or durability behavior.

## State-level layer

The State system includes the President, Presidential Palace officials, State-wide events and cross-state rules. Older community guides describe broad President powers, while current official patches continue to modify the Officials interface and term rewards.

## Wiki boundary

This article describes **what the game permits**. Server 504 agreements about who may attack, rotate Capital, use Armories, coordinate cross-state movement or appoint representatives belong in the Server Charter / Operational Codex instead.
