# Regulus — S-Tier Pet Agent

> **Last verified:** 8 Aug 2026  
> **Confidence:** High — current official version history.

**Regulus** is the newest officially announced S-tier Pet Agent in Dark War: Survival version `1.250.656`.

## Unlock requirement

Official patch notes state:

1. raise **Titan to Lv.50**;
2. complete the associated **rescue tasks**;
3. unlock Regulus.

The patch does not publish the exact rescue-task quantities, resource costs or State-age condition, so the Wiki leaves those fields open for Server 504 verification.

## Exclusive Skill — King's Decree

Official effect description:

**King's Decree increases Troop ATK for a certain duration.**

The official public patch note does not provide the percentage, duration, cooldown or number of free uses. Those values should be captured directly from the current in-game skill tooltip.

## Why Regulus matters

Regulus confirms several design directions for the Pet Agent system:

- later S-tier Agents are gated by investment in earlier Agents;
- rescue tasks remain relevant at the top end of the system;
- Pet-exclusive skills can provide direct battlefield effects rather than only passive account development.

## Investment implication

Because Regulus requires Titan Lv.50, Titan investment has an **unlock-option value** beyond Titan's own stats. A player planning for Regulus should therefore avoid evaluating Titan only by immediate CP gain.

This does not mean every player should rush Titan Lv.50 regardless of event timing. Pet resources now score in Alliance Duel and Survival Preparedness, so timing the final push can create significantly better resource efficiency.
