# Sacred Tree Blessing

> **Server 504 naming:** Season 4 · Sealed Island  
> **Last verified:** 7 Aug 2026  
> **Source confidence:** Medium. The event is documented consistently by Sealed Island community guides and has been observed in Server 504 seasonal context, but the exact reward/buff table is not confirmed by accessible official patch notes.

**Sacred Tree Blessing** is a Sealed Island seasonal activity built around collective contribution rather than direct PvP combat.

Community references describe players contributing a seasonal prayer item, commonly called **Omamori**, to advance a shared blessing meter associated with the Sacred Tree.

## Core idea

The event should be understood as a contribution cycle:

1. obtain the active contribution item through seasonal activities;
2. contribute it to the Sacred Tree event;
3. advance personal and/or collective progress;
4. unlock milestone rewards or temporary season benefits when thresholds are reached.

Community guides also describe alliance-level effects such as temporary buffs or purification support, but the exact implementation should be verified from the current Server 504 event panel before being listed as canonical.

## Omamori

Community sources identify **Omamori** as the contribution item used in Sacred Tree-related activities. They also warn that seasonal items can expire at the end of the season.

Because Sealed Island contains multiple event currencies and temporary items, players should check the item description before hoarding it for later weeks.

## Practical planning

When Sacred Tree Blessing is active:

- check whether contribution rewards have personal and alliance tracks;
- avoid spending the contribution item elsewhere until current event priorities are clear;
- coordinate alliance announcements if a shared threshold needs concentrated contributions;
- claim milestone rewards before the event phase closes;
- verify whether unused Omamori carries into the next phase or expires at season end.
