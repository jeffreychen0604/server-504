# Darian

> **Identity verified:** 7 Aug 2026  
> **Meta reviewed:** 15 Aug 2026  
> **Rarity:** S / Orange  
> **Faction:** Shooter  
> **Specialty:** Combat

Darian is a Shooter / Combat hero with an offense-oriented public kit centered on **Shooter ATK and troop skill damage**.

## Acquisition

Community data lists:

- Legend Battle Pass;
- Lucky Chest.

## Skill structure

### Absolute Order — Active Skill

Direct-damage Active Skill with an artillery-support presentation.

### Leader's Pride — Normal Attack

Standard Normal Attack progression.

### Supreme Glory — Passive Skill

Public data describes:

- increased Shooter ATK;
- additional troop skill damage through star progression.

This makes Darian especially relevant to Shooter formations whose damage profile already benefits from skill-damage investment.

### High Morale — Exclusive Talent

Public data lists hero ATK +10%, DEF +10% and troop capacity +5%.

## Current usefulness

**Decision label: Shooter combat core candidate / keep invested when already developed.**

Darian should be compared to other Shooter combat heroes by actual account state rather than tier labels alone. Stars, standard equipment, troop research, APC chips and Exclusive Equipment all materially affect whether replacing him is efficient.

### How to use this on Server 504

Treat these numbers as a **community reference point**, not a mandatory build order. Before pushing beyond the minimum target, compare:

1. Darian's current stars versus the other Shooter candidates on the account;
2. whether Shooter is the player's main faction;
3. actual battle-report skill-damage contribution;
4. the opportunity cost of the same gear materials on another core hero.

### Source conflict: Exclusive Equipment

The AllClash build article says Darian has no Exclusive Weapon available. That conflicts with official patch history already recorded by this Wiki, which explicitly references **Darian's Exclusive Equipment**.

**Server 504 rule:** the AllClash statement is treated as stale on this point; official patch history takes precedence.

## Exclusive Equipment

Official patch history explicitly mentions **Darian's Exclusive Equipment** when describing animation optimization, confirming that he participates in the system. Later official updates also added Red Star / Hall of Honor / swap mechanics to Exclusive Equipment generally.
