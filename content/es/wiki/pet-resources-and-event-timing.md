# Pet Resources & Event Timing

> **Última verificación:** 8 ago 2026  
> **Confianza:** oficial para integración de puntuación; observada en Server 504 para varios nombres; comunitaria para algunas fuentes/usos.

Los recursos Pet interactúan directamente con el scoring semanal, así que su valor depende también de **cuándo** se consumen.

## Nombres actuales de Server 504

- Advanced Tactical Rations;
- Nutrient Potion;
- Potential Chips;
- Spec Ops Honor Medals;
- Training Protocols.

Estos nombres son evidencia actual de Server 504. El efecto exacto, valor por uso y puntos requieren capturas UI antes de publicar una tabla fija.

## Integración oficial

La versión `1.250.650` añadió misiones de objetos Pet a:

- **Survival Preparedness — Unit Training**;
- **Alliance Duel — Holistic Growth**.

Los objetos Pet deben seguir la misma disciplina save/spend que Hero fragments, Wisdom Medals, Power Cores y Precision Parts.

## Nota de timing Server 504

El calendario double-dip actual incluye una ventana Pet Training el viernes de **12:00–15:59 server time** para los recursos anteriores.

Es una práctica operativa de Server 504, no una regla universal. La rotación puede cambiar.

## Etiquetas comunitarias

Guías recientes también usan Pet Feed / Tactical Rations, Advanced Training Manual, Pet breakthrough materials y Medals of Honor. No se asume equivalencia uno-a-uno con las etiquetas actuales del inventario de Server 504 sin capturas.

## Política recomendada

Para cada material conviene registrar: nombre exacto, icono, función principal, fuente, puntos Alliance Duel, puntos Survival Preparedness, límite semanal y última verificación.

## Regla de gasto

Salvo que un unlock inmediato o breakpoint de combate sea más importante, preferir gastar cuando el recurso puntúe en **dos sistemas a la vez**.
