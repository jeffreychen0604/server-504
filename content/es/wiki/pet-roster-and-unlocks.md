# Pet Roster & Unlock Path

> **Última verificación:** 8 ago 2026  
> **Confianza:** oficial para la condición de Regulus; comunitaria para roster temprano y secuencia de desbloqueo.

Los Pet Agents siguen una progresión escalonada. Las guías comunitarias describen Agents tempranos y medios que desbloquean al siguiente al alcanzar ciertos niveles.

## Roster temprano documentado por la comunidad

### Sentinel — Green / C-tier

Rol: recolección y logística. Habilidad reportada: **Instant Loot**, que limpia/recoge instantáneamente un punto de recursos. Una guía 2026 sitúa Sentinel Lv.30 como hito para desbloquear **Shining**.

### Shining — Blue / B-tier

Rol: expansión de tropas/apoyo militar. Habilidad reportada: **Rapid Mod**, que entrega un lote de las tropas de mayor tier actual de la cuenta.

### Zeus — Blue / B-tier

Rol: economía de recursos Pet. Habilidad reportada: **Wilderness Gift**, que genera Tactical Rations y otros materiales Pet.

## Agents posteriores

La comunidad veterana también menciona **Titan, Frost y Specter**, con Titan frecuentemente priorizado. Las fuentes públicas aún no ofrecen una tabla limpia y consistente de rareza, nivel previo y Rescue; esos datos siguen `VERIFY SERVER 504`.

## Regulus — S-tier

Requisito oficial:

- Titan llega a **Lv.50**;
- completar las tareas Rescue de Regulus.

Habilidad exclusiva: **King's Decree**, aumenta temporalmente Troop ATK.

Ver [Regulus](#/wiki/pet-regulus).

## No sobreinterpretar tiers comunitarios

Las etiquetas C/B/A/S ayudan a orientarse pero no sustituyen la rareza mostrada en el juego. Las capturas de Server 504 deben convertirse en la fuente canónica del roster.

## Verificación pendiente

Capturar:

- lista completa y orden de desbloqueo;
- rareza/color;
- nivel necesario para cada Rescue siguiente;
- requisitos de tareas Rescue;
- habilidad exclusiva, efecto y cooldown;
- posibles gates por edad del Estado o progreso de cuenta.
