# Shadow Calls & Pet Rescue

> **Última verificación:** 8 ago 2026  
> **Confianza:** oficial para Pet Agent Rescue como sistema y para el requisito de Rescue de Regulus; respaldada por comunidad para la relación entre Shadow Calls y el farmeo de recursos Pet.

La progresión de Pet Agents incluye una capa de **Rescue** y, según las guías comunitarias actuales, un bucle de dispatch/economía mediante **Shadow Calls**.

## Pet Agent Rescue

Las notas oficiales de lanzamiento de Pet Agents enumeran explícitamente **Pet Agent Rescue** entre los sistemas desbloqueados a través del Special Ops Outpost.

El parche oficial más reciente de Regulus ofrece un ejemplo concreto de un Pet Agent bloqueado por Rescue:

- primero alcanzar **Titan Lv.50**;
- después completar las rescue tasks requeridas;
- Regulus queda disponible para desbloquear.

Esto sugiere que la progresión Pet no consiste solo en subir niveles y gastar materiales: los Agents posteriores también pueden exigir una fase de Rescue.

## Shadow Calls

Una guía comunitaria actual sobre Pets identifica los dispatches de Shadow Calls como una fuente recurrente de materiales de progresión Pet, incluidos objetos de experiencia/crecimiento, materiales relacionados con breakthrough y recompensas tipo badge.

También informa de etiquetas de misión como:

- Logistics;
- Combat;
- Tech.

Según esa guía, emparejar un Agent con el arquetipo solicitado por la misión mejora la probabilidad de obtener un mejor resultado de dispatch.

Como las tablas exactas de recompensas y las fórmulas de éxito no son datos oficiales públicos, permanecen como `COMMUNITY / VERIFY SERVER 504`.

## Regla práctica de dispatch

1. Mantén activos los slots de dispatch siempre que sea posible.
2. Empareja tags/arquetipos de Agent con los requisitos de misión cuando la UI haga esa distinción.
3. Prioriza recursos Pet escasos sobre recursos genéricos cuando el valor sea comparable.
4. No gastes inmediatamente objetos Pet raros tras obtenerlos si se acerca una ventana de double dip de Alliance Duel / Survival Preparedness.

## No confundir sistemas

`Shadow Calls` existía antes que Pet Agents y conserva mecánicas de recompensa más amplias. Por eso el Wiki **no** afirma que cada tarea de Shadow Calls sea una tarea Pet. La evidencia comunitaria actual solo indica que se ha convertido en un canal útil para la progresión Pet.
