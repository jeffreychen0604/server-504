# Chip Factory

> **Última verificación:** 7 ago 2026  
> **Confianza de fuentes:** alta para el propósito del Chip Factory y el despliegue oficial del Chip System; media para el mapeo comunitario de materiales. No se ha encontrado un nivel personal oficial de Watchtower.

El **Chip Factory** es la parte de crafting dirigido del Modified Vehicle Chip System. Permite usar chip materials para fabricar chips del APC en vez de depender solo de cofres aleatorios.

## Dónde encaja

El desarrollador presentó el Chip System como una función para **craft and install chips**. Walkthroughs comunitarios muestran **Chip Factory** como una opción dedicada dentro de la interfaz de chips/vehicle cuando el sistema está disponible.

Las notas oficiales explican el rollout por State/fecha, pero **no publican un nivel personal independiente de Watchtower** para acceder al Chip Factory. El Wiki Server 504 no debe inventar un requisito WT.

Si un jugador tiene Chip Materials pero no ve Chip Factory, primero debe comprobar que el Chip System esté activo y abrir la interfaz Modified Vehicle/chips. Una captura del menú bloqueado o ausente es la mejor evidencia para documentar cualquier requisito personal adicional.

## Propósito del crafting

Guías comunitarias describen Chip Factory como alternativa determinista a los cofres aleatorios:

- **Common Chip Materials** para Purple chips;
- **Advanced Chip Materials** para Orange chips.

Las cantidades pueden cambiar, por lo que los costos exactos deben capturarse en la pantalla actual de Server 504.

## Estructura de chips descrita por la comunidad

- facciones Fighter, Rider y Shooter;
- tipos Deployment, Assault, Suppression y Barrier;
- calidades Green, Blue, Purple y Orange;
- progresión star-up;
- cambios de facción / setups por formación.

Los valores exactos de skills y resonance deben verificarse en juego antes de crear tablas numéricas.

## Fuentes de materiales

Las notas oficiales confirman fuentes como:

- cofres 3, 6 y 9 de puntos del Daily Alliance Duel;
- eventos como Chip Chrono;
- determinados Mod Vehicle packs y recompensas.

Zombie Siege también puede otorgar Random Blue Chip Chests, es decir chips y no solo materiales de crafting.

## Captura Server 504 necesaria

1. pantalla de entrada del Chip Factory;
2. receta Purple y cantidad;
3. receta Orange y cantidad;
4. selección de facción/tipo;
5. confirmación y output;
6. límites diarios o cooldowns.
