# Float Parade

> **Nom utilisé sur Server 504 :** Season 4 · Sealed Island  
> **Dernière vérification :** 7 août 2026  
> **Confiance des sources :** Moyenne. Les guides communautaires placent régulièrement Float Parade dans le cycle Sealed Island, mais les règles exactes de score et rewards doivent être vérifiées en jeu.

**Float Parade** est un side event saisonnier de Sealed Island associé aux phases ultérieures d’escalade Blood Moon / Oni.

Les références communautaires le présentent comme une phase plus légère que les guerres de territoire, la gestion de Miasma ou les grands boss.

## Rôle dans la saison

Float Parade appartient à une séquence d’activités temporaires plutôt qu’à un système permanent. Sa valeur pratique vient donc de :

- rewards saisonniers ;
- missions ou milestones limités ;
- activité pendant les fenêtres de moindre intensité ;
- contribution à l’économie de currencies/events de la saison.

Certains guides relient Float Parade à une procession **Kitsune King** et à la transition vers des phases tardives de Sealed Island. Il faut considérer ce vocabulaire comme communautaire sauf s’il apparaît dans l’UI actuelle de Server 504.

## Checklist pratique

Lorsque Float Parade apparaît :

1. lire les règles actuelles avant de dépenser des objets saisonniers ;
2. vérifier si la participation est limitée à une fenêtre horaire ;
3. identifier si les rewards sont personnels, alliance-wide ou basés sur un ranking ;
4. vérifier l’expiration de la currency ;
5. ne pas supposer que route, stage ou reward table sont identiques à la rotation précédente.

## Pourquoi cette page évite les chiffres fixes

Contrairement à Rotting Oni, Booze Brute et Oni King, Float Parade dispose de peu de références officielles accessibles décrivant son scoring actuel. Les guides publics donnent des descriptions, mais reprendre leurs chiffres comme données canoniques affaiblirait le standard de sources du Wiki.
