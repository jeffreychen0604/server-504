# Mutant Mines

> **Dernière vérification :** 8 août 2026  
> **Confiance :** Capture communautaire historique uniquement ; horaires, téléportations gratuites et plafonds de récompense doivent être vérifiés dans l’événement actif de Server 504.

Les **Mutant Mines** sont une activité inter-États de contrôle de ressources documentée par un ancien guide communautaire. Elle reste utile pour comprendre comment certains événements peuvent temporairement remplacer les règles ordinaires de frontière entre États, mais cette ancienne source n’est plus considérée comme autorité actuelle.

## Boucle historique documentée

L’ancien guide décrivait des Mutant Mines situées dans la Back Zone et protégées par une forte concentration virale, sauf pendant des fenêtres récurrentes de **sandstorm**. Pendant ces fenêtres, les survivants pouvaient entrer dans des États du même groupe de saison et contester les mines.

Les horaires historiques étaient :

- 01:00 heure serveur ;
- 10:00 heure serveur ;
- 19:00 heure serveur ;

avec une fenêtre de virus réduit d’une heure.

Ces horaires sont conservés uniquement comme cibles d’enquête. Le panneau Rules actif de Server 504 doit les confirmer avant toute publication comme règle actuelle.

## Ressources

L’ancienne description indique que les mines capturées produisaient continuellement :

- **Antigens** ;
- **Crimson Ores**.

La collecte contribuait également aux points de collecte de l’alliance. Le guide mentionnait un plafond quotidien pour les ressources personnelles mais pas pour la contribution de points d’alliance.

## Mouvement inter-États

L’archive mentionnait **3 téléportations inter-États gratuites par jour** pendant les périodes actives. Cette valeur n’est pas canonique actuellement et ne doit pas être généralisée à State of Supremacy ou à d’autres systèmes inter-États.

## Restrictions de combat

La documentation historique indiquait aussi que les joueurs inter-États ne pouvaient pas attaquer les Watchtowers hors Lost Lands, tandis que la zone Lost Lands / Capital supprimait cette restriction. Cela reste une règle historique propre à l’événement jusqu’à reconfirmation.

## Couche stratégique

Mutant Mines combine trois objectifs : sécuriser une position pendant la fenêtre active, capturer ou conserver les mines productives, puis convertir la collecte personnelle en contribution de classement d’alliance. Une bonne organisation exige donc des groupes de combat et du temps de collecte, pas seulement du PvP.
