# Shadow Calls & Pet Rescue

> **Dernière vérification :** 8 août 2026  
> **Confiance :** officielle pour Pet Agent Rescue comme système et pour le verrou de sauvetage de Regulus ; communautaire pour le lien entre Shadow Calls et le farming de ressources Pet.

La progression des Pet Agents comprend une couche **Rescue** et, selon les guides communautaires actuels, une boucle de dispatch/économie via **Shadow Calls**.

## Pet Agent Rescue

Les notes officielles de lancement des Pet Agents citent explicitement **Pet Agent Rescue** parmi les systèmes débloqués via le Special Ops Outpost.

Le dernier patch officiel de Regulus fournit un exemple concret de progression verrouillée par Rescue :

- atteindre d'abord **Titan Lv.50** ;
- terminer ensuite les rescue tasks requises ;
- Regulus devient déverrouillable.

Cela indique que la progression Pet n'est pas seulement une accumulation de niveaux et de matériaux : les Agents plus avancés peuvent aussi demander une étape de Rescue.

## Shadow Calls

Un guide communautaire Pet actuel présente les dispatches de Shadow Calls comme une source récurrente de matériaux de progression Pet, notamment des objets d'expérience/croissance, des matériaux liés aux breakthroughs et des récompenses de type badge.

Il mentionne aussi des tags de mission tels que :

- Logistics ;
- Combat ;
- Tech.

Associer un Agent à l'archétype demandé par la mission est signalé comme améliorant les chances d'un meilleur résultat de dispatch.

Les tables de récompenses exactes et les formules de taux de succès n'étant pas publiées officiellement, elles restent `COMMUNITY / VERIFY SERVER 504`.

## Règle pratique de dispatch

1. Garder les slots de dispatch actifs autant que possible.
2. Faire correspondre les tags/archétypes des Agents aux exigences de mission lorsque l'UI distingue ces rôles.
3. Privilégier les ressources Pet rares plutôt que les ressources génériques lorsque leur valeur est comparable.
4. Ne pas dépenser immédiatement les objets Pet rares après collecte si une fenêtre de double dip Alliance Duel / Survival Preparedness approche.

## Ne pas confondre les systèmes

`Shadow Calls` existait avant les Pet Agents et conserve ses propres mécaniques de récompense plus larges. Le Wiki ne prétend donc **pas** que chaque tâche Shadow Calls est une tâche Pet. Les données communautaires actuelles indiquent seulement qu'il est devenu un canal utile pour la progression Pet.
