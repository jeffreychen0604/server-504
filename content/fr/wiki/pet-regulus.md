# Regulus — Pet Agent S-Tier

> **Dernière vérification :** 8 août 2026  
> **Confiance :** élevée — historique officiel de version actuel.

**Regulus** est le Pet Agent S-tier le plus récent officiellement annoncé dans Dark War: Survival version `1.250.656`.

## Condition de déverrouillage

Les notes de patch officielles indiquent :

1. monter **Titan au Lv.50** ;
2. terminer les **rescue tasks** associées ;
3. déverrouiller Regulus.

Le patch ne publie pas les quantités exactes des rescue tasks, les coûts en ressources ni une éventuelle condition liée à l'âge du State. Le Wiki laisse donc ces champs ouverts pour vérification sur Server 504.

## Exclusive Skill — King's Decree

Description officielle de l'effet :

**King's Decree augmente Troop ATK pendant une certaine durée.**

La note de patch publique ne donne pas le pourcentage, la durée, le cooldown ni le nombre d'utilisations gratuites. Ces valeurs doivent être capturées directement depuis le tooltip actuel en jeu.

## Pourquoi Regulus est important

Regulus confirme plusieurs orientations du système Pet Agent :

- les Agents S-tier avancés peuvent être verrouillés derrière l'investissement dans des Agents antérieurs ;
- les rescue tasks restent pertinentes dans l'endgame du système ;
- les Pet-exclusive skills peuvent produire des effets directs au combat, et pas seulement des bonus passifs de développement de compte.

## Implication pour l'investissement

Comme Regulus exige Titan Lv.50, l'investissement dans Titan possède une **valeur d'option de déverrouillage** au-delà des propres stats de Titan. Un joueur qui vise Regulus ne doit donc pas juger Titan uniquement selon le gain immédiat de CP.

Cela ne signifie pas qu'il faut pousser Titan Lv.50 sans tenir compte du timing. Les ressources Pet donnent maintenant des points dans Alliance Duel et Survival Preparedness ; synchroniser le dernier push peut nettement améliorer l'efficacité des ressources.
