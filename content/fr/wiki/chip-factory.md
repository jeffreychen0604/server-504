# Chip Factory

> **Dernière vérification :** 7 août 2026  
> **Confiance des sources :** élevée pour le rôle du Chip Factory et le déploiement officiel du Chip System ; moyenne pour la correspondance communautaire des matériaux. Aucun niveau personnel officiel de Watchtower n’a été trouvé.

Le **Chip Factory** est la branche de craft ciblé du Modified Vehicle Chip System. Au lieu de dépendre uniquement de coffres aléatoires, il permet d’utiliser des chip materials pour fabriquer des chips destinées à l’APC.

## Où il se situe

Le développeur a introduit le Chip System comme une fonction permettant de **craft and install chips** pour le Modified Vehicle. Les walkthroughs communautaires du système actif montrent **Chip Factory** comme option dédiée dans l’interface chips/vehicle lorsque le Chip System est disponible.

Les notes officielles décrivent le déploiement par State/date mais ne publient **aucun niveau personnel séparé de Watchtower** pour l’accès au Chip Factory. Le Wiki Server 504 ne doit donc pas inventer un prérequis WT.

Si un joueur possède des Chip Materials mais ne voit pas Chip Factory, il faut d’abord vérifier que le Chip System est actif pour le compte/State et ouvrir l’interface Modified Vehicle/chips. Une capture du menu verrouillé ou absent est la meilleure preuve pour documenter un éventuel prérequis supplémentaire.

## Objectif du craft

Les guides communautaires décrivent Chip Factory comme l’alternative déterministe aux coffres aléatoires :

- **Common Chip Materials** pour le craft Purple ;
- **Advanced Chip Materials** pour le craft Orange.

Les quantités pouvant être ajustées, les coûts exacts doivent être capturés sur l’écran actuel de Server 504 avant d’entrer dans une table permanente.

## Structure des chips documentée par la communauté

Les walkthroughs récents décrivent régulièrement :

- trois factions : Fighter, Rider, Shooter ;
- quatre rôles/types : Deployment, Assault, Suppression, Barrier ;
- des qualités Green, Blue, Purple, Orange ;
- la progression star-up ;
- le changement de faction / les setups spécifiques aux formations.

Les valeurs exactes de skills et seuils de resonance doivent rester à vérifier en jeu.

## Sources de matériaux

Les notes officielles confirment notamment :

- 3e, 6e et 9e coffres de paliers du Daily Alliance Duel ;
- événements liés aux chips comme Chip Chrono ;
- certains Mod Vehicle packs et récompenses d’événements.

Zombie Siege peut aussi donner des Random Blue Chip Chests, donc des chips plutôt que seulement des matériaux bruts.

## Capture Server 504 nécessaire

Pour finaliser les recettes exactes, capturer :

1. écran d’entrée du Chip Factory ;
2. recette Purple et quantité ;
3. recette Orange et quantité ;
4. choix faction/type ;
5. confirmation et résultat du craft ;
6. limites quotidiennes ou cooldowns.
