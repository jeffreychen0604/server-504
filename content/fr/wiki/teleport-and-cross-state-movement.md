# Teleport & Cross-State Movement

> **Dernière vérification :** 8 août 2026  
> **Confiance :** élevée pour le comportement cross-state officiel actuel.

Les règles de téléportation ont beaucoup changé depuis le lancement ; les anciens guides peuvent donc être trompeurs.

## Modèle cross-state actuel

L'historique officiel indique que pendant les événements cross-state compatibles :

- la téléportation n'envoie plus le joueur à un emplacement aléatoire dans le State cible ;
- la destination peut être choisie directement ;
- la carte du State adverse peut être touchée pour se téléporter pendant **State of Supremacy** et **Alliance Duel — Enemy Buster** ;
- les **Advanced Teleporters** fonctionnent dans Lost Lands autour du Capital ;
- l'ancien **Capital Teleporter** a été retiré de l'Alliance Shop ;
- s'il en reste dans l'inventaire, ils sont consommés avant les Advanced Teleporters à l'entrée dans Lost Lands.

## Couleurs des noms sur la carte

Les patches officiels ont aussi modifié l'identification visuelle cross-state :

- les survivants d'autres States présents dans votre Home State apparaissent en rouge ;
- pendant State of Supremacy, les troupes/noms du même State apparaissent en jaune ;
- d'autres alliances du même State peuvent aussi utiliser le jaune dans les contextes compatibles ;
- les survivants hors affrontement cross-state peuvent apparaître en blanc.

Ces couleurs servent de repère UI, pas de règle diplomatique.

## Protection same-State pendant State of Supremacy

Les règles officielles actuelles empêchent les attaques contre les autres survivants du même State pendant State of Supremacy.

## Règles saisonnières

Les saisons de conquête peuvent remplacer les règles normales. Dans Origin Lands, des patches officiels ont par exemple autorisé la téléportation sur des tiles du même camp/alliance tout en conservant la propriété de la tile sous le shelter déplacé.

Ces règles doivent rester étiquetées par saison.

## Planification des Advanced Teleporters

La limite hebdomadaire de l'Alliance Shop pour les Advanced Teleporters a été officiellement augmentée de **1 à 4** dans un patch 2026. Cette valeur peut encore changer ; le shop live reste prioritaire.
