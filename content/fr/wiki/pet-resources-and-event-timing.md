# Pet Resources & Event Timing

> **Dernière vérification :** 8 août 2026  
> **Confiance :** officielle pour l’intégration au scoring ; observée sur Server 504 pour plusieurs noms de ressources ; communautaire pour certaines sources/utilisations.

Les ressources Pet interagissent directement avec le scoring hebdomadaire : leur valeur dépend donc aussi du **moment** où elles sont consommées.

## Noms actuellement suivis sur Server 504

- Advanced Tactical Rations ;
- Nutrient Potion ;
- Potential Chips ;
- Spec Ops Honor Medals ;
- Training Protocols.

Ces noms constituent une observation Server 504 actuelle. Leur effet exact, valeur par utilisation et score associé nécessitent encore des captures UI avant publication d’un tableau numérique fixe.

## Intégration officielle au scoring

La version `1.250.650` a ajouté des missions liées aux objets Pet dans :

- **Survival Preparedness — Unit Training** ;
- **Alliance Duel — Holistic Growth**.

Les objets Pet doivent donc suivre la même discipline save/spend que les Hero fragments, Wisdom Medals, Power Cores et Precision Parts.

## Note de timing Server 504

Le planning double-dip actuel de Server 504 contient une fenêtre Pet Training le vendredi **12:00–15:59 server time** pour les ressources ci-dessus.

C’est un planning opérationnel Server 504, pas une règle universelle du jeu. La rotation des événements peut changer.

## Labels communautaires

Des guides récents utilisent aussi des noms génériques comme Pet Feed / Tactical Rations, Advanced Training Manual, Pet breakthrough materials ou Medals of Honor. Ils ne sont pas automatiquement équivalents aux labels actuels de l’inventaire Server 504.

## Politique d’inventaire recommandée

Pour chaque matériau, enregistrer à terme : nom exact, capture d’icône, fonction principale, source, points Alliance Duel, points Survival Preparedness, limite hebdomadaire et date de dernière vérification.

## Règle de dépense

Sauf déblocage immédiat d’un Agent ou breakpoint combat plus important, préférer la dépense lorsqu’une ressource marque des points dans **deux systèmes simultanément**.

## Captures prioritaires

1. tooltip de chaque ressource Pet ;
2. écran de scoring du vendredi ;
3. écran de level-up ;
4. écran breakthrough ;
5. écran training/refinement ;
6. boutique Pet et limites.
