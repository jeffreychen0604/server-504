# Honor Shop

> **Dernière vérification :** 7 août 2026  
> **Confiance :** élevée pour les règles officielles de fusion/conversion ; moyenne pour le stock exact du Server 504.  
> **Statut Server 504 :** vérifier l’interface en direct car le déploiement a été progressif selon les States.

Le **Honor Shop** est le système d’échange unifié introduit pour remplacer plusieurs anciennes boutiques PvP/événement.

## Migration officielle

Les notes de mise à jour indiquent la fusion de :

- Capital Shop ;
- Black Gold Shop ;
- Arena Shop

vers le **Honor Shop**.

Les monnaies gagnées dans :

- State of Supremacy ;
- Capital Clash ;
- Black Gold Battlefield

ont également été remplacées par des **Honor Points**.

### Conversion des monnaies

Conversion officielle annoncée :

- **1 Capital Glory Badge = 40 Honor Points** ;
- **1 Black Gold Coin = 2 Honor Points**.

## Pourquoi les anciens guides sont différents

De nombreuses pages de 2025 placent encore Power Cores, Boost Ores, Orange Versatile Hero Fragments, Titanium Alloy ou Design Blueprints dans Capital/Arena/Black Gold Shop. Elles restent utiles pour retracer les anciennes sources, mais le nom de la boutique peut être obsolète après la migration Honor.

## Catégories de forte valeur actuelles

Des guides communautaires récents de 2026 citent notamment :

- équipement Orange / choice boxes ;
- Power Cores ;
- DX Blueprints.

L’inventaire exact, le coût et les limites hebdomadaires doivent être vérifiés sur le Server 504.

## Logique de priorité suggérée

Pour un compte construisant encore sa formation principale :

1. équipement Orange garanti ou progression ciblée ;
2. Power Cores lorsque l’équipement Orange atteint le palier concerné ;
3. DX Blueprints lorsque le breakthrough d’équipement rouge est réellement accessible ;
4. matériaux secondaires/farmables après les goulots précédents.

C’est un cadre de décision, pas un tableau de prix fixe.
