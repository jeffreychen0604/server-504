# Pet Roster & Unlock Path

> **Dernière vérification :** 8 août 2026  
> **Confiance :** officielle pour la condition de Regulus ; communautaire pour le roster antérieur et la séquence de déblocage.

Les Pet Agents suivent une progression par étapes. Les guides communautaires décrivent des Agents early/mid-game qui débloquent le suivant lorsqu’un palier de niveau est atteint.

## Roster communautaire initial

### Sentinel — Green / C-tier

Rôle communautaire : récolte et logistique. Compétence rapportée : **Instant Loot**, qui termine/récupère instantanément un point de ressource. Un guide 2026 indique Sentinel Lv.30 comme palier de déblocage de **Shining**.

### Shining — Blue / B-tier

Rôle : soutien de l’armée / expansion des troupes. Compétence rapportée : **Rapid Mod**, fournissant un lot des troupes du tier le plus élevé actuellement disponible sur le compte.

### Zeus — Blue / B-tier

Rôle : économie de ressources Pet. Compétence rapportée : **Wilderness Gift**, générant Tactical Rations et d’autres matériaux de croissance Pet.

## Agents ultérieurs

La communauté vétéran cite également **Titan, Frost et Specter**. Les sources publiques disponibles ne fournissent pas encore un tableau propre et cohérent de leur rareté, niveau requis et tâches Rescue : ces données restent `VERIFY SERVER 504`.

## Regulus — S-tier

Condition officielle :

- Titan atteint **Lv.50** ;
- terminer les tâches Rescue de Regulus.

Compétence exclusive : **King's Decree**, qui augmente temporairement Troop ATK.

Voir [Regulus](#/wiki/pet-regulus).

## Ne pas surinterpréter les tiers communautaires

Les labels C/B/A/S des guides sont utiles pour s’orienter mais ne remplacent pas le label de rareté affiché dans l’UI actuelle. Les captures Server 504 doivent devenir la source canonique du roster.

## File de vérification

À capturer :

- liste complète des Agents dans l’ordre de déblocage ;
- rareté/couleur ;
- niveau requis pour chaque prochain Rescue ;
- exigences des tâches Rescue ;
- nom/effet/cooldown de la compétence exclusive ;
- éventuel verrou d’âge d’État ou de progression du compte.
