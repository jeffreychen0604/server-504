# Special Ops Outpost

> **Dernière vérification :** 8 août 2026  
> **Confiance :** officielle pour le rôle de déblocage du bâtiment ; communautaire pour le comportement détaillé des sous-systèmes.

Le **Special Ops Outpost** est le bâtiment qui débloque le système Pet Agent de Dark War: Survival.

## Modèle officiel de déblocage

La version `1.250.650` indique de construire le Special Ops Outpost **lorsque le scénario le demande**. Une fois disponible, il ouvre notamment :

- Rescue ;
- Training ;
- Growth.

Les notes officielles ne publient ni prérequis Watchtower ni jour d’État fixe. Le Wiki n’en invente donc aucun.

## Ce que les joueurs peuvent y trouver

Les guides communautaires le décrivent comme le hub pour :

- gérer les Pet Agents débloqués ;
- progresser en niveaux et breakthroughs ;
- effectuer Special Training / refinement ;
- avancer dans les chaînes Rescue ;
- lancer des activités de dispatch de type Shadow Calls.

Les noms exacts d’onglets peuvent varier selon la langue et les patchs.

## Importance opérationnelle

**Progression de niveau → déblocage d’Agents ultérieurs → bonus passifs/compétences plus fortes → consommation de ressources Pet pendant Alliance Duel / Survival Preparedness.**

Le bâtiment est donc un hub de progression, pas un décor.

## Données non encore canoniques

À capturer sur Server 504 :

- prérequis exact de construction ;
- coût/temps de construction ;
- noms d’onglets dans l’UI anglaise actuelle ;
- quantités des tâches Rescue ;
- seuils de niveau au-delà de ceux officiellement confirmés ;
- limites quotidiennes/hebdomadaires des dispatches liés.

## Checklist pratique

1. Le construire dès que possible, sauf si cela détruit une fenêtre planifiée de score Construction.
2. Vérifier l’exigence du prochain Agent avant de consommer les matériaux rares.
3. Identifier quelles ressources Pet scorent dans Alliance Duel / Survival Preparedness.
4. Séparer la décision de progression Rescue de la décision de dépense des matériaux.
