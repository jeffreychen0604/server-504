# Sacred Tree Blessing

> **Nom utilisé sur Server 504 :** Season 4 · Sealed Island  
> **Dernière vérification :** 7 août 2026  
> **Confiance des sources :** Moyenne. L’event est décrit de façon cohérente par les guides communautaires Sealed Island et observé dans le contexte saisonnier de Server 504, mais les tables exactes de rewards/buffs ne sont pas confirmées par les patch notes accessibles.

**Sacred Tree Blessing** est une activité saisonnière fondée sur la contribution collective plutôt que sur le PvP direct.

Les références communautaires décrivent les joueurs donnant un objet de prière saisonnier, généralement appelé **Omamori**, pour faire progresser une jauge de blessing liée au Sacred Tree.

## Idée centrale

Le cycle de contribution peut être résumé ainsi :

1. obtenir l’objet de contribution actif via les activités saisonnières ;
2. le donner à l’event Sacred Tree ;
3. faire progresser les objectifs personnels et/ou collectifs ;
4. débloquer des milestone rewards ou bénéfices temporaires lorsque les seuils sont atteints.

Les guides mentionnent aussi des effets d’alliance, comme des buffs temporaires ou une aide à la purification, mais ceux-ci doivent être vérifiés sur le panneau actuel de Server 504 avant d’être déclarés canoniques.

## Omamori

Les sources communautaires identifient **Omamori** comme l’objet de contribution utilisé dans les activités Sacred Tree. Elles rappellent aussi que des objets saisonniers peuvent expirer à la fin de la saison.

Sealed Island utilisant plusieurs currencies et objets temporaires, il faut toujours lire la description de l’objet avant de le conserver pour plus tard.

## Planification pratique

Lorsque Sacred Tree Blessing est actif :

- vérifier s’il existe des tracks personnel et alliance ;
- éviter de dépenser l’objet ailleurs avant de connaître les priorités ;
- coordonner les annonces si un seuil collectif demande des contributions concentrées ;
- réclamer les rewards avant la fermeture de la phase ;
- vérifier si l’Omamori inutilisé est conservé ou expire.
