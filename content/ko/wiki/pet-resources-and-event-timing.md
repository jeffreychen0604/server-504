# Pet Resources & Event Timing

> **최종 확인:** 2026년 8월 8일  
> **신뢰도:** 이벤트 점수 연동은 공식 자료 기반. 여러 현재 자원명은 Server 504 관찰 기반. 일부 획득처/용도 설명은 커뮤니티 기반.

Pet 자원은 주간 이벤트 점수와 직접 연결되므로 가치가 **언제 소비하느냐**에 따라 달라집니다.

## Server 504 현재 추적 자원명

- Advanced Tactical Rations;
- Nutrient Potion;
- Potential Chips;
- Spec Ops Honor Medals;
- Training Protocols.

이 이름들은 현재 Server 504 관찰값입니다. 정확한 효과, 1회 사용량, 이벤트 점수는 현재 UI 캡처 전까지 고정 수치로 게시하지 않습니다.

## 공식 점수 연동

버전 `1.250.650`은 Pet 아이템 미션을 다음에 추가했습니다.

- **Survival Preparedness — Unit Training**;
- **Alliance Duel — Holistic Growth**.

따라서 Pet 아이템도 Hero fragments, Wisdom Medals, Power Cores, Precision Parts와 같은 save/spend 원칙으로 관리해야 합니다.

## Server 504 타이밍 메모

현재 Server 504 double-dip 일정에는 금요일 **12:00–15:59 server time** Pet Training 구간이 있으며 위 자원이 사용됩니다.

이는 Server 504 운영 일정이지 게임 전체의 영구 규칙이 아닙니다. 이벤트 로테이션은 변경될 수 있습니다.

## 커뮤니티 용어

최근 가이드에서는 Pet Feed / Tactical Rations, Advanced Training Manual, Pet breakthrough materials, Medals of Honor 같은 일반화된 이름도 사용합니다. Server 504 인벤토리 이름과 일대일로 대응한다고 가정하지 않습니다.

## 권장 인벤토리 정책

각 재료에 대해 추후 다음을 기록하는 것이 좋습니다: 정확한 게임 내 이름, 아이콘 캡처, 주요 용도, 획득처, Alliance Duel 점수, Survival Preparedness 점수, 주간 구매 한도, 최종 확인일.

## 소비 원칙

즉시 Agent 해금이나 전투 breakpoint가 더 중요하지 않다면 **두 시스템에서 동시에 점수가 되는 구간**에 소비하는 것을 우선합니다.

## 우선 캡처

1. 각 Pet 자원 tooltip;
2. 금요일 이벤트 점수 화면;
3. Pet level-up 화면;
4. breakthrough 화면;
5. training/refinement 화면;
6. Pet 관련 상점 및 제한.
