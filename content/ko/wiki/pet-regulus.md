# Regulus — S-Tier Pet Agent

> **최종 확인:** 2026년 8월 8일  
> **신뢰도:** 높음 — 최신 공식 버전 히스토리.

**Regulus**는 Dark War: Survival version `1.250.656`에서 공식 발표된 최신 S-tier Pet Agent입니다.

## 해금 조건

공식 패치 노트는 다음 조건을 명시합니다.

1. **Titan을 Lv.50**까지 성장;
2. 관련 **rescue tasks** 완료;
3. Regulus 해금.

공식 패치는 rescue task의 정확한 수량, 재료 비용, State age 조건을 공개하지 않습니다. 따라서 Wiki는 해당 항목을 Server 504 검증 대기로 유지합니다.

## Exclusive Skill — King's Decree

공식 효과 설명:

**King's Decree는 일정 시간 동안 Troop ATK를 증가시킵니다.**

공식 공개 노트에는 정확한 %, 지속시간, cooldown, 무료 사용 횟수가 없습니다. 이 값들은 현재 게임 내 skill tooltip에서 직접 캡처해야 합니다.

## Regulus가 중요한 이유

Regulus는 Pet Agent 시스템의 몇 가지 방향성을 확인해 줍니다.

- 후반 S-tier Agent는 이전 Agent 투자에 의해 해금될 수 있음;
- Rescue task는 시스템 최상위에서도 계속 중요함;
- Pet-exclusive skill은 계정 성장용 패시브뿐 아니라 전투에 직접 영향을 줄 수 있음.

## 투자 관점

Regulus가 Titan Lv.50을 요구하므로 Titan 투자는 Titan 자체 stats 외에도 **해금 옵션 가치**를 가집니다. Regulus를 목표로 하는 플레이어는 Titan을 단순한 즉시 CP 증가만으로 평가하면 안 됩니다.

그렇다고 event timing을 무시하고 무조건 Titan Lv.50을 서둘러야 한다는 뜻은 아닙니다. Pet 자원은 Alliance Duel과 Survival Preparedness에서도 점수를 제공하므로 마지막 성장 구간을 scoring window에 맞추면 자원 효율이 훨씬 좋아질 수 있습니다.

## 검증 대기 항목

Regulus가 Server 504에서 사용 가능해진 뒤 확보할 자료:

- 현재 해금 화면;
- rescue task 목록;
- King's Decree 정확한 ATK %;
- 지속시간;
- cooldown;
- 무료 사용 횟수 / reset cycle(해당 시);
- 레벨/breakthrough별 패시브 stats;
- training attribute pool;
- Agent rarity/icon 확인.
