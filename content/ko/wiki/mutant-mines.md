# Mutant Mines

> **마지막 확인:** 2026년 8월 8일  
> **신뢰도:** 과거 커뮤니티 기록만 존재. 정확한 일정, 무료 텔레포트 수, 보상 상한은 현재 Server 504 이벤트에서 재확인 필요.

**Mutant Mines**는 과거 커뮤니티 가이드에 기록된 cross-state 자원 점령 활동입니다. 일반 State 경계를 이벤트가 일시적으로 어떻게 덮어쓸 수 있는지 이해하는 데는 도움이 되지만, 원래 공개 소스는 더 이상 현재 기준 권위 자료로 취급하지 않습니다.

## 과거 기록된 이벤트 루프

아카이브 설명에 따르면 Back Zone의 Mutant Mines는 높은 바이러스 농도로 보호되다가 반복되는 **sandstorm window** 동안 접근 가능해졌습니다. 이 시간에는 같은 시즌 그룹의 다른 State로 이동해 광산을 경쟁할 수 있었습니다.

과거 문서의 하루 세 시간대는 다음과 같습니다.

- 서버 시간 01:00
- 서버 시간 10:00
- 서버 시간 19:00

각 저바이러스 window는 1시간으로 기록되어 있습니다.

이 시간은 현재 규칙이 아니라 **조사 대상**으로만 보존합니다. Server 504의 실제 이벤트 Rules 페이지 확인 전에는 현재 일정으로 게시하지 않습니다.

## 자원

과거 커뮤니티 설명은 점령된 Mutant Mines가 지속적으로 다음 자원을 생산했다고 기록합니다.

- **Antigens**
- **Crimson Ores**

채집은 Alliance gathering points에도 기여했습니다. 동일한 문서는 개인 자원 수집에는 일일 상한이 있지만 Alliance gathering-point 기여에는 상한이 없다고 설명했습니다.

## Cross-state 이동

아카이브에는 활성 Mutant Mines 시간 동안 **하루 3회의 무료 cross-state teleport**가 기록되어 있습니다.

이 수치는 현재 canonical이 아니며, State of Supremacy나 다른 cross-state 시스템으로 일반화해서는 안 됩니다.

## 전투 제한

과거 문서에서는 다른 State 플레이어가 Lost Lands 밖의 Watchtower를 공격할 수 없고, Lost Lands / Capital 지역에서는 그 제한이 해제되었다고 설명했습니다.

현재 Rules 패널에서 다시 확인되기 전까지는 이벤트 고유의 과거 규칙으로만 취급합니다.

## 전략 구조

Mutant Mines는 세 목표를 결합합니다.

1. 활성 window에서 유리한 위치 확보
2. 생산 광산 점령 및 유지
3. 개인 gathering을 Alliance ranking 기여로 전환

따라서 단순 PvP가 아니라 전투 그룹과 채집 uptime을 함께 운영해야 합니다.

## 확인이 필요한 항목

현재 Server 504 이벤트 Rules 화면에서 다음을 캡처해야 합니다.

- sandstorm windows
- 무료 teleport 수
- Antigens / Crimson Ores 일일 상한
- Alliance ranking 공식
- Watchtower 공격 제한
- mine tier와 생산량
