# Armory Assault

> **마지막 확인:** 2026년 8월 8일  
> **신뢰도:** 커뮤니티 검증 이벤트 규칙. Server 504의 Armory 배정 관행은 게임 메커니즘 문서에서 의도적으로 제외합니다.

Armory Assault는 **8개의 Armory** 중 하나를 장악하는 것을 중심으로 진행되는 동맹 대 동맹 이벤트입니다.

## 등록

현재 커뮤니티 자료에 따르면:

- 동맹장 또는 R4가 등록할 수 있습니다.
- 한 동맹은 최대 **2개의 Armory**에 등록할 수 있습니다.
- 등록 시 여러 시간대를 선택합니다.
- 여러 동맹이 같은 Armory를 신청하면 겹치는 선택 시간대를 기준으로 일정이 정해집니다.
- 이전 라운드에서 Armory를 보유했다면 다음 라운드에 같은 Armory로 자동 등록될 수 있습니다.
- 이벤트는 **4라운드 주기**로 운영되며 이후 Armory 점유 상태가 초기화됩니다.

이 규칙들은 최신 공식 패치 문구가 아니라 커뮤니티 출처이므로, 주기 구조가 바뀔 때마다 Server 504의 실제 등록 화면을 확인해야 합니다.

## 전투 규칙

커뮤니티 자료는 전투를 다음과 같이 설명합니다.

- 동맹은 rally를 통해 Armory를 공격합니다.
- 방어 측은 Armory에 reinforcement를 보냅니다.
- 전투는 최대 **2시간** 지속될 수 있습니다.
- **30분 동안 연속으로 점유**하면 해당 라운드의 Armory를 확보합니다.
- 어느 동맹도 30분 연속 점유를 달성하지 못하면 전투 종료 시점에 Armory를 점유 중인 동맹이 라운드에서 승리합니다.

## 참가 제한

등록 종료 후에 동맹에 가입한 플레이어는 해당 Armory 전투에 참가할 수 없을 수 있습니다. 따라서 등록 마감 전 roster 이동 시점이 중요합니다.

## 보상

8개의 Armory는 서로 다른 보상 카테고리를 제공할 수 있습니다. 커뮤니티 문서에는 다음과 같은 예가 있습니다.

- speedups
- Orange Hero Fragments
- equipment 관련 재료
- Boost Ores

중요한 점은 **보상 배정이 순환할 수 있다는 것**입니다. 따라서 Server 504 추적표에서는 Armory 자체의 위치/정체성과 현재 보상을 별도 필드로 관리해야 합니다.

## 게임 메커니즘 vs Server 504 배정

게임은 등록, 전투, 보상 메커니즘을 제공합니다. Server 504에서 어느 동맹이 어느 Armory를 사용하기로 자발적으로 합의하는 것은 **서버 운영 정책**이며, Armory Assault의 보편적인 게임 규칙이 아닙니다.

## 확인 대기 항목

현재 스크린샷으로 확인하면 좋은 항목:

- 등록 제한과 주기 라운드 수
- 정확한 5개 시간대
- 현재 8개 Armory 보상표
- 점령/유지 타이머 문구
- 참가 제한 문구
