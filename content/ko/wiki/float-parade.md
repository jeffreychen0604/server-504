# Float Parade

> **Server 504 명칭:** Season 4 · Sealed Island  
> **마지막 검증:** 2026년 8월 7일  
> **출처 신뢰도:** 중간. 커뮤니티 가이드에서 Float Parade를 Sealed Island 이벤트 주기에 일관되게 포함하지만 정확한 점수와 보상 규칙은 현재 게임 내 확인이 필요함.

**Float Parade**는 Blood Moon / Oni 격화 주기의 후반부와 연결되는 Sealed Island 시즌 부가 이벤트입니다.

커뮤니티 자료에서는 영토 전쟁, Miasma 관리, 주요 보스 전투보다 상대적으로 부담이 낮은 이벤트 단계로 설명합니다.

## 시즌에서의 역할

Float Parade는 영구 성장 시스템이 아니라 시즌 활동 흐름의 일부로 등장합니다. 실전 가치는 다음과 같습니다.

- 시즌 보상 획득;
- 한정 임무 또는 달성 목표 완료;
- 비교적 전투 강도가 낮은 시간대 참여;
- 시즌 이벤트/화폐 경제에 기여.

일부 가이드는 Float Parade를 **Kitsune King** 행렬 및 Sealed Island 후반 단계 전환과 연결합니다. 같은 명칭이 현재 Server 504 UI에 보이기 전에는 커뮤니티 용어로 취급해야 합니다.

## 실전 체크리스트

Float Parade가 열리면:

1. 시즌 아이템을 사용하기 전에 현재 이벤트 규칙을 읽는다.
2. 참여 가능 시간이 제한되어 있는지 확인한다.
3. 보상이 개인, 연맹 전체, 또는 순위 기반인지 확인한다.
4. 이벤트 화폐가 단계 종료 시 만료되는지 확인한다.
5. 이전 주기와 경로, 단계, 보상표가 동일하다고 가정하지 않는다.

## 숫자를 고정하지 않는 이유

Rotting Oni, Booze Brute, Oni King과 달리 Float Parade는 현재 점수 구조를 명확히 정의하는 공식 패치 항목을 쉽게 확인하기 어렵습니다. 공개 가이드에 설명은 있지만 그 보상표를 그대로 기준 데이터로 옮기면 Wiki의 출처 기준이 약해집니다.

## Server 504에서 추가로 확인할 항목

- 이벤트 시작 조건;
- 이벤트 지속 시간;
- 단계/경로 구조;
- 참여 행동;
- 점수 규칙;
- 시즌 화폐 획득량;
- 달성 보상;
- 순위 보상;
- 참여에 행동력 또는 이벤트 전용 아이템이 필요한지.

**Rules** 및 **Rewards** 탭의 스크린샷 몇 장만 확보해도 이 문서를 커뮤니티 기반 개요에서 검증된 Server 504 참고 자료로 올릴 수 있습니다.
