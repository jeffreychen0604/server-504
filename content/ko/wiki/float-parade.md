# Float Parade

> **Server 504 명칭:** Season 4 · Sealed Island  
> **마지막 검증:** 2026년 8월 7일  
> **출처 신뢰도:** 중간. 커뮤니티 가이드에서 Float Parade를 Sealed Island event cycle에 포함하지만 정확한 scoring/reward 규칙은 현재 게임 내 검증이 필요함.

**Float Parade**는 Blood Moon / Oni escalation 후반부와 연결되는 Sealed Island 시즌 side event다.

커뮤니티 자료에서는 territory war, Miasma 관리, 주요 boss 전투보다 상대적으로 부담이 낮은 이벤트 단계로 설명한다.

## 시즌 내 역할

Float Parade는 영구 progression system이 아니라 시즌 활동 순환의 일부다. 실전 가치는 다음에 있다.

- 시즌 reward 획득
- 한정 mission 또는 milestone 완료
- 비교적 낮은 강도의 시간대에 참여
- 시즌 event/currency 경제에 기여

일부 가이드는 Float Parade를 **Kitsune King** 행렬 및 Sealed Island 후반 단계 전환과 연결한다. 같은 명칭이 현재 Server 504 UI에 보이기 전에는 커뮤니티 용어로 취급한다.

## 실전 체크리스트

Float Parade 등장 시:

1. 시즌 아이템을 쓰기 전에 현재 규칙을 읽는다.
2. 참여 시간 window가 있는지 확인한다.
3. reward가 개인, alliance-wide, ranking 기반인지 확인한다.
4. event currency의 만료 시점을 확인한다.
5. 이전 rotation의 route/stage/reward table이 그대로 반복된다고 가정하지 않는다.

## 숫자를 고정하지 않는 이유

Rotting Oni, Booze Brute, Oni King과 달리 Float Parade의 현재 scoring model을 명확히 정의하는 공식 패치 자료가 쉽게 확인되지 않는다. 공개 가이드의 정확한 reward table을 canonical로 복사하면 Wiki의 source standard가 약해진다.

## Server 504에서 추가로 캡처할 항목

- event opening condition
- duration
- stage/route 구조
- 참여 action
- scoring 규칙
- 시즌 currency drop
- milestone rewards
- ranking rewards
- stamina 또는 event-only item 소비 여부

Rules와 Rewards 탭의 screenshot 몇 장만 확보해도 이 페이지를 커뮤니티 기반 개요에서 검증된 Server 504 reference로 올릴 수 있다.
