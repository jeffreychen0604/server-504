# Watchtower 진행 참고표

> **최종 검증:** 2026년 8월 7일  
> **출처 신뢰도:** 전체 진행 구조는 높음. 정확한 선행 조건은 현재 커뮤니티 자료가 여러 레벨에서 충돌하므로 중간.

**Watchtower**는 Shelter 성장의 핵심 진행 관문이다. 건물 상한, Research 접근, 병력 성장을 열어 주지만 Watchtower 화면에 표시되는 비용만이 실제 비용의 전부는 아니다. 선행 건물도 먼저 완료해야 한다.

## 신뢰도가 높은 진행 패턴

여러 Dark War: Survival 자료가 다음의 큰 구조에는 대체로 일치한다.

- 초반에는 기본 Shelter 건물이 선행 조건으로 사용된다.
- **Alliance Hall**은 대략 WT9 이후부터 반복적인 병목이 된다.
- **Research Center**는 주요 구간마다 다시 선행 조건으로 등장한다.
- 상위 구간에서는 Fighter, Rider, Shooter Camp가 선행 조건 체인에 번갈아 들어간다.
- 중반부터 Iron과 Electricity가 자원 부담에 포함된다.
- WT30은 Industrial 진행으로 넘어가는 전환점이다.

## 비용 데이터 주의

공개 표에는 서로 다른 두 종류의 값이 섞여 있다.

- **기본 / 보정 전 비용**
- Megan 같은 Hero의 건설 자원 절감 효과가 적용된 비용

예를 들어 일부 고레벨 WT 커뮤니티 표는 이미 Megan의 건설 효과로 줄어든 수치를 보여 준다. 이를 기본 비용 표와 직접 비교하면 안 된다.

Server 504 Wiki는 현재 게임 내 비용 화면을 캡처하고 건설 버프 적용 여부까지 기록하기 전에는 WT1–WT30 확정 계산기를 공개하지 않는다.

## 실전 진행 규칙

Watchtower 업그레이드를 시작하면 가능할 때 두 번째 건설 큐에서 바로 다음 Watchtower 레벨의 선행 건물을 준비한다. 이렇게 하면 대기 시간을 줄이고 Alliance Hall이나 특정 faction Camp가 다음 병목이 되는 것을 막을 수 있다.

## Server 504 검증 목표

이 문서를 확정표로 만드는 가장 빠른 방법은 WT10, WT13, WT14, WT21, WT22, WT26의 **Required Buildings** 패널을 캡처하는 것이다. 현재 공개 자료가 충돌하는 구간들이다.
