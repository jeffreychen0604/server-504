# Sacred Tree Blessing

> **Server 504 명칭:** Season 4 · Sealed Island  
> **마지막 검증:** 2026년 8월 7일  
> **출처 신뢰도:** 중간. Sealed Island 커뮤니티 가이드에서 일관되게 설명되고 Server 504 시즌 환경에서도 관찰되었지만, 정확한 보상/buff 표는 현재 접근 가능한 공식 패치 기록만으로 확인되지 않음.

**Sacred Tree Blessing**은 직접적인 PvP 전투보다 공동 기여에 초점을 둔 Sealed Island 시즌 활동입니다.

커뮤니티 자료에서는 **Omamori**라고 불리는 시즌 기도 아이템을 Sacred Tree에 기여해 공동 Blessing 게이지를 올리는 방식으로 설명합니다.

## 핵심 구조

이 이벤트는 다음과 같은 기여 주기로 이해할 수 있습니다.

1. 시즌 활동을 통해 현재 기여 아이템을 얻는다.
2. Sacred Tree 이벤트에 기여한다.
3. 개인 및/또는 공동 진행도를 올린다.
4. 기준에 도달하면 달성 보상이나 임시 시즌 효과를 해금한다.

일부 가이드는 임시 buff나 정화 지원 같은 연맹 단위 효과도 설명합니다. 정확한 적용 방식은 현재 Server 504 이벤트 화면에서 확인된 뒤에 기준 데이터로 다루는 것이 좋습니다.

## Omamori

커뮤니티 자료는 **Omamori**를 Sacred Tree 관련 활동의 기여 아이템으로 설명합니다. 시즌 아이템은 시즌 종료 시 만료될 수 있다는 경고도 있습니다.

Sealed Island에는 여러 이벤트 화폐와 임시 아이템이 있으므로, 장기간 보관하기 전에 아이템 설명을 확인해야 합니다.

## 실전 계획

Sacred Tree Blessing이 진행 중일 때:

- 기여 보상이 개인과 연맹 트랙으로 나뉘는지 확인한다.
- 현재 우선순위가 정해지기 전에는 기여 아이템을 다른 곳에 쓰지 않는다.
- 공동 목표에 집중 기여가 필요하면 연맹 공지를 맞춘다.
- 이벤트 단계가 끝나기 전에 달성 보상을 수령한다.
- 남은 Omamori가 다음 단계로 넘어가는지, 시즌 종료 시 만료되는지 확인한다.

## Server 504에서 추가로 확인할 항목

- 정확한 이벤트 지속 시간;
- Omamori 획득처;
- 1회 기여량;
- 개인 달성 보상;
- 연맹 달성 보상;
- Blessing buff 종류와 지속 시간;
- 게이지가 연맹 전체, 서버 전체, 또는 개인 + 공동 구조인지;
- 사용하지 않은 기여 아이템의 만료 규칙.

이 값들이 확인되기 전까지는 숫자 보상표보다 **메커니즘과 계획 방법**을 중심으로 문서를 유지합니다.
