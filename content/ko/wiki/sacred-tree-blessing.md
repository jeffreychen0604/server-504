# Sacred Tree Blessing

> **Server 504 명칭:** Season 4 · Sealed Island  
> **마지막 검증:** 2026년 8월 7일  
> **출처 신뢰도:** 중간. Sealed Island 커뮤니티 가이드에서 일관되게 설명되며 Server 504 시즌 환경에서도 관찰되었지만 정확한 reward/buff 표는 접근 가능한 공식 패치 노트로 확인되지 않음.

**Sacred Tree Blessing**은 직접 PvP가 아니라 공동 기여를 중심으로 하는 Sealed Island 시즌 활동이다.

커뮤니티 자료에서는 플레이어가 보통 **Omamori**라고 불리는 시즌 기도 아이템을 기여해 Sacred Tree의 blessing meter를 올리는 방식으로 설명한다.

## 핵심 구조

기여 루프는 다음처럼 이해할 수 있다.

1. 시즌 활동에서 현재 기여 아이템을 획득한다.
2. Sacred Tree event에 기여한다.
3. 개인 및/또는 공동 진행도를 올린다.
4. threshold에 도달하면 milestone reward 또는 임시 시즌 효과를 해금한다.

일부 가이드는 임시 buff나 purification 지원 같은 연맹 단위 효과도 설명하지만, 현재 Server 504 event panel에서 확인되기 전에는 canonical로 확정하지 않는다.

## Omamori

커뮤니티 자료는 **Omamori**를 Sacred Tree 활동의 기여 아이템으로 설명하며 시즌 아이템이 시즌 종료 시 만료될 수 있다고 경고한다.

Sealed Island에는 여러 임시 currency와 item이 있으므로 이후 주차를 위해 저장하기 전에 item description을 확인해야 한다.

## 실전 계획

Sacred Tree Blessing 활성 시:

- 개인/연맹 reward track이 모두 있는지 확인
- 현재 우선순위가 정해지기 전 다른 곳에 기여 아이템을 쓰지 않기
- 공동 threshold가 집중 기여를 요구하면 연맹 공지로 조율
- phase 종료 전에 milestone reward 수령
- 남은 Omamori가 다음 단계로 이월되는지 또는 시즌 종료 시 만료되는지 확인

## Server 504에서 추가로 캡처할 항목

- 정확한 event duration
- Omamori 획득처
- 1회 기여량
- personal milestone rewards
- alliance milestone rewards
- 정확한 blessing buffs와 지속 시간
- meter 범위: alliance-wide, server-wide, 또는 individual + collective
- 미사용 item 만료 규칙

이 값이 확인되기 전까지 이 문서는 숫자 reward table보다 **메커니즘과 계획 방법**을 중심으로 유지한다.
