# Chip Factory

> **최종 확인:** 2026년 8월 7일  
> **출처 신뢰도:** Chip Factory 목적과 공식 Chip System rollout은 높음; 커뮤니티 제작 재료 매핑은 중간. 개인 Watchtower 공식 해금 레벨은 확인되지 않음.

**Chip Factory**는 Modified Vehicle Chip System의 지정 제작 기능입니다. 랜덤 chip chest에만 의존하지 않고 chip materials를 사용해 APC용 chips를 제작할 수 있습니다.

## 시스템 내 위치

개발사는 Chip System을 Modified Vehicle용 **craft and install chips** 기능으로 소개했습니다. 현재 시스템을 다룬 커뮤니티 walkthrough에서는 Chip System이 활성화된 뒤 chips/vehicle 인터페이스 안에 **Chip Factory**가 별도 옵션으로 표시됩니다.

공식 패치 노트는 State/날짜 기준 rollout은 설명하지만 Chip Factory 접근을 위한 **별도의 개인 Watchtower 레벨을 공개하지 않습니다**. 따라서 Server 504 Wiki는 WT 해금 조건을 임의로 만들지 않습니다.

Chip Materials를 보유했는데 Chip Factory가 보이지 않는다면 먼저 계정/State에서 Chip System이 활성화되어 있는지 확인하고 Modified Vehicle/chips 인터페이스를 열어야 합니다. 잠금 또는 메뉴 부재 화면 캡처가 추가 개인 조건을 문서화하는 가장 좋은 증거입니다.

## 제작 목적

커뮤니티 가이드는 Chip Factory를 랜덤 chest의 결정론적 대안으로 설명합니다.

- **Common Chip Materials** → Purple chip 제작
- **Advanced Chip Materials** → Orange chip 제작

필요 수량은 조정될 수 있으므로 정확한 비용은 현재 Server 504 Chip Factory 화면을 캡처한 뒤에만 영구 표에 추가해야 합니다.

## 커뮤니티에서 확인되는 chip 구조

- Fighter / Rider / Shooter 세 faction
- Deployment / Assault / Suppression / Barrier 네 역할/type
- Green / Blue / Purple / Orange 품질
- star-up 성장
- faction 전환 / 편성별 chip setup

정확한 skill 수치와 resonance threshold는 인게임 확인 전까지 숫자 표로 확정하지 않습니다.

## 제작 재료 획득처

공식 패치에서 확인된 예:

- Daily Alliance Duel 3·6·9번째 포인트 단계 상자
- Chip Chrono 같은 chip 이벤트
- 일부 Mod Vehicle pack 및 이벤트 보상

Zombie Siege는 raw material만이 아니라 Random Blue Chip Chests도 제공합니다.

## Server 504에서 필요한 캡처

1. Chip Factory 진입 화면
2. Purple 레시피와 수량
3. Orange 레시피와 수량
4. faction/type 선택 방식
5. 제작 확인 및 결과
6. 일일 제한 또는 cooldown
