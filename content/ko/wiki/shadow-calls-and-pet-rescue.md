# Shadow Calls & Pet Rescue

> **최종 확인:** 2026년 8월 8일  
> **신뢰도:** Pet Agent Rescue 시스템 자체와 Regulus의 Rescue 조건은 공식 근거, Shadow Calls와 Pet 자원 파밍의 연계는 커뮤니티 근거.

Pet Agent 성장에는 **Rescue** 단계가 포함되며, 현재 커뮤니티 가이드에 따르면 **Shadow Calls**를 통한 dispatch/경제 루프도 활용됩니다.

## Pet Agent Rescue

공식 Pet Agent 출시 노트는 Special Ops Outpost를 통해 해금되는 시스템 중 하나로 **Pet Agent Rescue**를 명시합니다.

최신 Regulus 공식 패치는 Rescue가 Pet Agent 해금 조건으로 작동하는 구체적인 예시를 제공합니다.

- 먼저 **Titan Lv.50** 달성;
- 필요한 rescue tasks 완료;
- 이후 Regulus 해금 가능.

즉 Pet 성장은 단순한 레벨/재료 소모만이 아니라, 후반 Agent의 경우 별도의 Rescue 단계까지 요구될 수 있습니다.

## Shadow Calls

현재 커뮤니티 Pet 가이드는 Shadow Calls dispatch를 Pet 성장 재료의 반복 수급처로 설명합니다. 여기에는 경험치/성장 아이템, breakthrough 관련 재료, badge 계열 보상 등이 포함됩니다.

또한 다음과 같은 미션 태그가 언급됩니다.

- Logistics;
- Combat;
- Tech.

가이드에 따르면 미션이 요구하는 유형과 Agent의 태그/아키타입을 맞추면 더 좋은 dispatch 결과를 얻을 가능성이 높아집니다.

정확한 보상표와 성공률 공식은 공식 공개 데이터가 아니므로 `COMMUNITY / VERIFY SERVER 504` 상태로 유지합니다.

## 실전 dispatch 원칙

1. 가능한 한 dispatch 슬롯을 계속 가동합니다.
2. UI가 구분을 제공한다면 Agent 태그/아키타입을 미션 요구사항과 맞춥니다.
3. 보상 가치가 비슷하다면 일반 자원보다 희귀 Pet 성장 자원을 우선합니다.
4. Alliance Duel / Survival Preparedness double-dip 구간이 가깝다면 희귀 Pet 아이템을 획득 즉시 소비하지 않습니다.

## 시스템 혼동 금지

`Shadow Calls`는 Pet Agents보다 먼저 존재했으며 더 넓은 자체 보상 구조를 갖고 있습니다. 따라서 Wiki는 **모든 Shadow Calls 임무가 Pet 임무라고 주장하지 않습니다**. 현재 커뮤니티 근거는 Shadow Calls가 Pet 성장의 유용한 수급 채널 중 하나가 되었다는 점만 뒷받침합니다.

## 검증 대기 항목

Server 504에서 다음 화면을 확보해야 합니다.

- Shadow Calls 미션 카테고리/태그;
- Pet Agent 참여 조건;
- Great Success 문구와 보너스;
- Pet 전용 보상 아이템 전체;
- 일일 dispatch 횟수 / refresh 규칙;
- 각 Agent의 Rescue 단계;
- State age에 따라 Rescue 조건이 달라지는지 여부.
