# 병력 Tier 진행

> **최종 검증:** 2026년 8월 7일  
> **출처 신뢰도:** 중간. 현재 공개 Dark War: Survival 자료는 여러 정확한 unlock 레벨에서 서로 충돌한다.

병력 전투력은 troop tier에 따라 크게 상승하지만, 외부 표가 서로 다를 때 Wiki가 거짓 정밀도를 제공해서는 안 된다.

## 안정적으로 확인되는 메커니즘

병력 진행은 다음 요소의 조합으로 제한된다.

- Watchtower 진행
- 해당 Fighter, Rider 또는 Shooter Camp 레벨
- Battle / faction Research 요구 조건
- 이후 Industrial 진행

이 중 하나만 올려도 다음 troop tier가 여전히 잠겨 있을 수 있다.

## 현재 출처 충돌

한 상세 진행표는 다음 Watchtower milestone 패턴을 제시한다.

| Troop tier | 커뮤니티 진행표 |
| --- | ---: |
| T1 | WT3 |
| T2 | WT6 |
| T3 | WT9 |
| T4 | WT12 |
| T5 | WT15 |
| T6 | WT18 |
| T7 | WT21 |
| T8 | WT24 |
| T9 | WT27 |
| T10 | WT30 |

하지만 같은 커뮤니티 사이트의 다른 페이지는 T5를 WT11 부근, T8을 WT22 부근, T10을 WT28 부근처럼 더 이른 milestone으로 설명한다. 두 설명이 동시에 동일한 현재 unlock 규칙일 수는 없다.

## 독립적인 타당성 확인

과거 플레이어 계정 판매 글은 약하지만 참고 가능한 보조 근거를 제공한다.

- WT25 계정이 T8 병력으로 광고된 사례
- WT28 계정이 T9 병력으로 광고된 사례
- WT29 계정이 T9 병력으로 광고된 사례
- WT30 / Industrial 계정은 일반적으로 T10 병력을 광고

이런 판매 글은 공식 게임 문서가 아니지만, 이른 unlock 주장보다 **WT24 / WT27 / WT30** 패턴이 더 그럴듯하다는 약한 근거가 된다.

## 현재 Wiki의 표현 원칙

Server 504에서 실제 unlock 화면을 캡처하기 전까지 위 표는 **커뮤니티 참고값**으로만 취급하며 현재 확정 규칙으로 표현하지 않는다.

실전 계획에서는:

1. 주력 faction Camp를 Watchtower 상한에 가깝게 유지한다.
2. Battle/faction Research를 병행한다.
3. 새 troop tier를 위해 speedup을 쓰기 전 Camp의 다음 troop 항목을 열어 정확한 요구 조건을 확인한다.
4. 요구 조건 화면을 캡처하여 Server 504 Wiki가 커뮤니티 추정을 실제 게임 근거로 대체할 수 있게 한다.

## Industrial 병력

일반 T10 이후 Industrial 업그레이드는 Industrial Watchtower와 faction Camp 진행을 통해 추가 late-game 전투력 층을 제공한다. 정확한 Industrial troop unlock은 일반 WT1–30 패턴이 아니라 현재 Industrial 진행 트리에 의존하므로 별도로 문서화해야 한다.

## Server 504 검증 목표

가치가 가장 높은 스크린샷은 다음 잠금 troop 상세 화면이다.

- T8
- T9
- T10
- 첫 Industrial troop upgrade

각 화면에는 요구 Camp 레벨과 Research 조건이 함께 보여야 한다.
