# Pet Roster & Unlock Path

> **최종 확인:** 2026년 8월 8일  
> **신뢰도:** Regulus 조건은 공식 자료 기반. 초기 Pet roster와 해금 순서는 커뮤니티 기반.

Pet Agents는 단계형 성장 구조를 따릅니다. 커뮤니티 가이드는 초기/중반 Agents가 특정 레벨에 도달하면 다음 Agent의 Rescue가 열리는 방식으로 설명합니다.

## 커뮤니티 기록 초기 roster

### Sentinel — Green / C-tier

역할: 자원 채집 및 물류. 보고된 스킬 **Instant Loot**는 자원 지점을 즉시 정리/회수하는 효과로 설명됩니다. 2026년 커뮤니티 가이드는 Sentinel Lv.30을 **Shining** 해금 기준으로 제시합니다.

### Shining — Blue / B-tier

역할: 병력 확장/군대 지원. 보고된 스킬 **Rapid Mod**는 현재 계정에서 가장 높은 tier의 병력을 일정량 제공합니다.

### Zeus — Blue / B-tier

역할: Pet 자원 경제. 보고된 스킬 **Wilderness Gift**는 Tactical Rations와 기타 Pet 성장 재료를 생성합니다.

## 후속 Agents

베테랑 커뮤니티에서는 **Titan, Frost, Specter**도 중요하게 언급하며 Titan을 우선하는 경우가 많습니다. 하지만 공개 자료만으로는 세 Agent의 정확한 희귀도, 이전 Agent 요구 레벨, Rescue 조건을 일관되게 확정할 수 없습니다. 따라서 해당 데이터는 `VERIFY SERVER 504` 상태를 유지합니다.

## Regulus — S-tier

공식 조건:

- Titan **Lv.50**;
- Regulus Rescue 과제 완료.

전용 스킬 **King's Decree**는 일시적으로 Troop ATK를 증가시킵니다.

자세한 내용은 [Regulus](#/wiki/pet-regulus)를 참고하세요.

## 커뮤니티 tier를 과도하게 해석하지 않기

C/B/A/S 표기는 방향을 잡는 데 유용하지만 현재 게임 UI의 희귀도 표기를 대신할 수 없습니다. 최종 roster 기준은 Server 504의 실제 UI 캡처가 되어야 합니다.

## 검증 항목

다음 내용을 현재 Pet Agent UI에서 캡처해야 합니다.

- 전체 Agent 목록과 해금 순서;
- 각 Agent의 희귀도/색상;
- 다음 Rescue를 여는 데 필요한 레벨;
- Rescue 과제 조건;
- 전용 스킬 이름/효과/cooldown;
- State age 또는 계정 진행도에 따른 gate 여부.
