# Special Ops Outpost

> **최종 확인:** 2026년 8월 8일  
> **신뢰도:** 건물의 해금 역할은 공식 자료 기반. 세부 하위 기능은 커뮤니티 기반.

**Special Ops Outpost**는 Dark War: Survival의 Pet Agent 시스템을 해금하는 건물입니다.

## 공식 해금 방식

버전 `1.250.650`은 스토리 진행 안내에 따라 Special Ops Outpost를 건설한다고 설명합니다. 이용 가능해지면 다음 시스템이 열립니다.

- Rescue;
- Training;
- Growth.

공식 패치 노트에는 Watchtower 요구 레벨이나 고정 State 날짜가 명시되어 있지 않습니다. 따라서 Wiki는 이를 임의로 설정하지 않습니다.

## 내부에서 기대할 수 있는 기능

커뮤니티 가이드는 Outpost를 다음 기능의 허브로 설명합니다.

- 해금된 Pet Agents 관리;
- 레벨 및 breakthrough 성장;
- Special Training / 속성 refinement;
- Rescue 해금 체인;
- Shadow Calls 유형의 dispatch 활동.

정확한 탭 이름은 언어와 패치에 따라 달라질 수 있습니다.

## 운영상 중요한 이유

**Pet 레벨 성장 → 후속 Agent 해금 → 더 강한 패시브/전용 스킬 확보 → Alliance Duel / Survival Preparedness 점수 구간에서 Pet 재료 사용.**

즉 장식 건물이 아니라 성장 허브입니다.

## 아직 확정하지 않는 데이터

Server 504 UI에서 확인이 필요한 항목:

- 정확한 건설 선행조건;
- 건설 비용/시간;
- 현재 영어 UI 탭 이름;
- Rescue 과제 수량;
- 공식적으로 확인된 것 외의 Agent 레벨 해금 조건;
- 관련 dispatch의 일/주간 제한.

## 실전 체크리스트

1. 등장하면 가능한 빨리 건설하되, 예정된 Construction 점수 구간을 크게 손해 보지 않도록 조정합니다.
2. 희귀 재료를 쓰기 전에 다음 Agent의 해금 요구조건을 확인합니다.
3. 현재 Alliance Duel / Survival Preparedness에서 어떤 Pet 자원이 점수를 주는지 확인합니다.
4. Rescue 진행과 재료 소비를 별개의 결정으로 봅니다.
