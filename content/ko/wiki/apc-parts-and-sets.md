# APC Parts & Parts Set

> **최종 확인:** 2026년 8월 7일  
> **출처 신뢰도:** 현재 Parts Set과 Gears 제거는 높음, 과거 해금 레벨과 재료 표는 중간.

**Modified Vehicle Parts**는 차량의 기본 Modify 레벨 및 APC chips와 별도로 성장하는 시스템입니다.

## Parts Set

2025년 10월 공식 패치에서 **Parts Set** 기능이 추가되었습니다.

- **6개 parts 모두** set 시스템에 참여
- 6개 parts를 특정 레벨까지 올리면 추가 능력치 보너스 획득
- 더 높은 set milestone에서 새로운 Modified Vehicle 스킨 해금 가능

보너스가 6개 parts 전체에 연동되므로 한 부품만 과도하게 올리면 중요한 set milestone이 늦어질 수 있습니다. 정확한 임계값은 현재 Server 504 UI에서 확인해야 합니다.

## 중요한 자원 변경

같은 공식 패치에서 Modified Vehicle Parts 업그레이드의 **Gears** 요구가 제거되었고, 이전에 parts에 사용한 Gears는 환급되었습니다.

따라서 Gears를 parts의 영구 업그레이드 재료로 적어 둔 초기 커뮤니티 표는 현재 기준으로 폐기해야 합니다.

## Design Blueprints와 Titanium Alloy

과거 커뮤니티 자료는 **Titanium Alloy**와 **Design Blueprints**를 APC/parts 성장 재료로 기록합니다. Design Blueprint는 고급 parts 자원으로 설명되며 Season Shop, Black Gold Shop, 일부 offer가 과거 획득처로 언급됩니다.

용어 자체는 참고할 수 있지만, 시스템 cap과 재료 규칙이 확대되었으므로 현대 part 레벨의 정확한 비용은 다시 캡처해야 합니다.

## 현재 cap 주의

2025년 초 APC 표에는 훨씬 낮은 part/vehicle cap이 적혀 있었습니다. 이후 공식 업데이트에서 Modify는 **Lv.500**까지 확대되고 Parts Set이 추가되었으며, **all parts Lv.66**가 Tactical Modification 해금 조건 중 하나가 되었습니다.

따라서:

- 오래된 “parts max 42”를 현재 기준으로 사용하지 않기
- 과거 Gears 비용 사용 금지
- 모든 숫자 표에 버전/검증 날짜 남기기

## 업그레이드 계획

1. 6개 parts의 다음 Parts Set milestone 확인
2. set milestone과 단일 part 업그레이드 효율 비교
3. 희귀 재료를 의미 있는 threshold에 보존
4. 가능하면 큰 업그레이드를 점수 이벤트와 맞추기
5. 모든 parts 성장 자체가 Tactical Modification 해금에도 기여함을 기억하기
