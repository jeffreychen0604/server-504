# Alliance Tech

> **최종 확인:** 2026년 8월 8일  
> **신뢰도:** 시스템 목적은 높음. 정확한 트리와 수치 보너스는 현재 게임 캡처가 더 필요합니다.

Alliance Tech는 멤버의 기부로 성장하는 공동 Tech 트리입니다. 개인 Research Center Tech와 달리 Alliance Tech는 Alliance 전체에 혜택을 줍니다.

## 기능

현재 커뮤니티 가이드는 크게 두 범주를 설명합니다.

- **성장 보너스** — 건설/연구 효율 및 기타 계정 성장 효과;
- **전투 보너스** — 부대 ATK/DEF 및 기타 군사 효과.

정확한 Tech 이름, 최대 레벨, 보너스 값은 변경될 수 있으므로 Wiki는 아직 완전한 수치 트리를 공개하지 않습니다.

## 기부 루프

안정적인 플레이 흐름은 다음과 같습니다.

1. Alliance Tech를 엽니다.
2. Alliance가 현재 우선순위로 지정한 Tech에 기부합니다.
3. 해당되는 경우 Alliance contribution/currency를 받습니다.
4. 리더십이 기부 방향을 조정하여 낮은 우선순위의 여러 브랜치로 자원이 흩어지지 않게 합니다.

## 집중 기부가 중요한 이유

Alliance Tech는 공동 자원 풀입니다. 열 명이 서로 다른 열 개의 브랜치에 기부하는 것보다 같은 양의 기부로 먼저 높은 영향도의 Tech 하나를 완성하는 편이 즉각적인 가치가 더 클 수 있습니다.

이는 **게임 시스템 관찰**이며 Server 504의 거버넌스 규칙이 아닙니다. 어떤 Tech를 우선할지는 각 Alliance 리더십이 시즌, 이벤트, roster 상황에 따라 결정합니다.

## 추가로 필요한 데이터

현재 UI에서 다음 항목을 캡처해야 완전한 데이터베이스가 됩니다.

- Tech 카테고리;
- Tech 이름;
- 레벨 / 최대 레벨;
- 기부 요구량;
- 표시되는 경우 Alliance 자원 요구량;
- 레벨당 효과;
- 선행 Tech.
