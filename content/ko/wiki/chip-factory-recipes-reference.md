# Chip Factory 레시피 참고

> **최종 확인:** 2026년 8월 8일  
> **신뢰도:** 재료 종류와 공식 획득처는 높음; Orange 제작 정확한 비용은 중간; Purple 비용은 Server 504 화면 캡처가 아직 필요함.

Chip Factory는 vehicle chip을 목표 지정 방식으로 제작하는 경로입니다. 안정적인 시스템 구조는 먼저 [Chip Factory](#/wiki/chip-factory)와 [APC Chips](#/wiki/apc-chips)를 참고하세요. 이 문서는 시간이 지나며 낡을 수 있는 레시피/재료 수치를 별도로 검증하기 위한 감사 페이지입니다. 같은 이유로 [Resource Calculators](#/wiki/wiki-calculators)의 Orange 재료 비용은 직접 수정할 수 있게 유지됩니다.

## 안정적으로 확인된 구조

커뮤니티 자료는 일관되게 다음과 같이 설명합니다.

- **Purple Chips → Common Chip Materials**
- **Orange Chips → Advanced Chip Materials**

공식 패치 기록은 Chip System 도입과 함께 Daily Alliance Duel 포인트 보상 상자 **3, 6, 9단계**에 Chip Materials가 추가되었음을 확인합니다. 같은 업데이트에서 Zombie Siege에는 Random Blue Chip Chests가 추가되었습니다.

## 정확한 레시피 감사

| 레시피 항목 | 현재 Wiki 상태 |
| --- | --- |
| Purple Chip 재료 종류 | Common Chip Materials — 커뮤니티 근거 |
| Purple Chip 정확한 비용 | **VERIFY SERVER 504** |
| Orange Chip 재료 종류 | Advanced Chip Materials — 커뮤니티 근거 |
| Orange Chip 정확한 비용 | **800 Advanced Chip Materials — 커뮤니티 관측; 게임 내 확인 필요** |
| faction/type 선택 제작 | 커뮤니티 근거 |

Orange 레시피의 800 재료 비용은 여러 플레이어 관측에서 반복적으로 나타나 계획용으로 유용하지만, 현재 공식 패치 노트에는 정확한 제작 비용이 공개되어 있지 않습니다. 따라서 Wiki는 신뢰도 표시를 숨기지 않습니다.

## Chip Chest 재료 관측

널리 사용되는 커뮤니티 가이드는 다음을 보고합니다.

- Purple Chip Chest: 30 Advanced Chip Materials + chip roll;
- Orange Chip Chest: 100 Advanced Chip Materials + Orange chip 확정.

Server 504 스크린샷으로 확인되기 전까지 이 수치는 **커뮤니티 데이터**로 취급하며 공식 상수로 보지 않습니다.

## 현재 중요한 규칙

공식 버전 기록에서 확인되는 내용:

- Chip Materials는 Daily Alliance Duel 3 / 6 / 9단계 포인트 상자에서 획득;
- Zombie Siege에 Random Blue Chip Chests 포함;
- 이후 pack 개편으로 Mod Vehicle Material Chests와 Random Purple/Green Chip Chests가 포함됨;
- Orange vehicle chip 하나가 **10★**에 도달하면 Tactical Modification 해금 조건 중 하나를 충족할 수 있음.

## 권장 Server 504 캡처

확정 레시피 표를 만들려면 Chip Factory 화면에서 다음을 캡처하세요.

1. Purple 레시피와 Common material 요구량;
2. Orange 레시피와 Advanced material 요구량;
3. faction 선택기;
4. chip type 선택기;
5. Watchtower/Modified Vehicle 관련 해금 조건;
6. 현재 reset/star-up 문구.
