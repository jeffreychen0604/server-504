# Pet Resources & Event Timing

> **Última verificação:** 8 ago 2026  
> **Confiança:** oficial para integração de pontuação; observada no Server 504 para vários nomes; comunitária para algumas fontes/usos.

Os recursos Pet interagem diretamente com a pontuação semanal, então seu valor também depende de **quando** são consumidos.

## Nomes atuais no Server 504

- Advanced Tactical Rations;
- Nutrient Potion;
- Potential Chips;
- Spec Ops Honor Medals;
- Training Protocols.

Esses nomes são evidência atual do Server 504. Efeito exato, valor por uso e pontuação ainda exigem captura da UI antes de uma tabela numérica fixa.

## Integração oficial

A versão `1.250.650` adicionou missões de itens Pet em:

- **Survival Preparedness — Unit Training**;
- **Alliance Duel — Holistic Growth**.

Itens Pet devem seguir a mesma disciplina save/spend usada para Hero fragments, Wisdom Medals, Power Cores e Precision Parts.

## Nota de timing do Server 504

O calendário double-dip atual inclui uma janela Pet Training na sexta-feira **12:00–15:59 server time** para os recursos acima.

Isso é uma prática operacional do Server 504, não uma regra universal. A rotação dos eventos pode mudar.

## Rótulos comunitários

Guias recentes também usam Pet Feed / Tactical Rations, Advanced Training Manual, Pet breakthrough materials e Medals of Honor. Não se assume equivalência direta com os labels atuais do inventário do Server 504 sem screenshots.

## Política recomendada

Para cada material, registrar futuramente: nome exato, screenshot do ícone, função principal, fonte, pontos Alliance Duel, pontos Survival Preparedness, limite semanal e última verificação.

## Regra de gasto

Salvo se um unlock imediato ou breakpoint de combate for mais importante, prefira gastar quando o recurso pontuar em **dois sistemas ao mesmo tempo**.

## Capturas prioritárias

1. tooltip de cada recurso;
2. tela de scoring de sexta-feira;
3. tela de level-up;
4. breakthrough;
5. training/refinement;
6. loja Pet e limites.
