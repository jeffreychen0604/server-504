# Shadow Calls & Pet Rescue

> **Última verificação:** 8 ago 2026  
> **Confiança:** oficial para Pet Agent Rescue como sistema e para o requisito de Rescue de Regulus; apoiada pela comunidade para a relação entre Shadow Calls e farming de recursos Pet.

A progressão de Pet Agents inclui uma camada de **Rescue** e, segundo guias comunitários atuais, um ciclo de dispatch/economia por meio de **Shadow Calls**.

## Pet Agent Rescue

As notas oficiais de lançamento dos Pet Agents citam explicitamente **Pet Agent Rescue** entre os sistemas desbloqueados pelo Special Ops Outpost.

O patch oficial mais recente de Regulus fornece um exemplo concreto de um Pet Agent bloqueado por Rescue:

- primeiro alcançar **Titan Lv.50**;
- depois concluir as rescue tasks exigidas;
- Regulus fica disponível para desbloqueio.

Isso indica que a progressão Pet não é apenas subir nível e gastar materiais: Agents posteriores também podem exigir uma etapa de Rescue.

## Shadow Calls

Um guia comunitário atual identifica dispatches de Shadow Calls como fonte recorrente de materiais de progressão Pet, incluindo itens de experiência/crescimento, materiais ligados a breakthrough e recompensas do tipo badge.

Também relata tags de missão como:

- Logistics;
- Combat;
- Tech.

Segundo esse guia, combinar um Agent com o arquétipo pedido pela missão melhora a chance de um resultado melhor no dispatch.

Como as tabelas exatas de recompensas e fórmulas de taxa de sucesso não são dados oficiais públicos, permanecem como `COMMUNITY / VERIFY SERVER 504`.

## Regra prática de dispatch

1. Mantenha os slots de dispatch ativos sempre que possível.
2. Combine tags/arquétipos do Agent com os requisitos da missão quando a UI fizer essa distinção.
3. Priorize recursos Pet escassos em vez de recursos genéricos quando o valor for comparável.
4. Não gaste imediatamente itens Pet raros após coletá-los se uma janela de double dip de Alliance Duel / Survival Preparedness estiver próxima.

## Não confundir sistemas

`Shadow Calls` existia antes dos Pet Agents e mantém mecânicas próprias de recompensa mais amplas. Por isso, o Wiki **não** afirma que toda tarefa de Shadow Calls seja uma tarefa Pet. A evidência comunitária atual apenas indica que ele se tornou um canal útil para progressão Pet.
