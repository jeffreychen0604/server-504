# Pet Resources & Event Timing

> **Xác minh gần nhất:** 8/8/2026  
> **Độ tin cậy:** Chính thức đối với event-scoring integration; Server 504-observed đối với một số resource name hiện tại; community-backed đối với một số mô tả về nguồn/cách dùng.

Pet resources hiện tương tác trực tiếp với weekly event scoring, vì vậy giá trị của chúng một phần phụ thuộc vào **thời điểm** được tiêu.

## Resource name hiện tại cần theo dõi trên Server 504

Server 504 hiện đã sử dụng các tên Pet Training resource gồm:

- Advanced Tactical Rations;
- Nutrient Potion;
- Potential Chips;
- Spec Ops Honor Medals;
- Training Protocols.

Các tên này được coi là current Server 504 evidence. Effect chính xác, giá trị mỗi lần dùng và scoring value của từng item vẫn cần current UI capture trước khi Wiki công bố bảng số cố định.

## Tích hợp scoring chính thức

Phiên bản `1.250.650` thêm Pet-item mission vào:

- **Survival Preparedness — Unit Training**;
- **Alliance Duel — Holistic Growth**.

Do đó Pet items nên áp dụng cùng save/spend discipline đang dùng với Hero fragments, Wisdom Medals, Power Cores và Precision Parts.

## Timing note cho Server 504

Double-dip schedule hiện tại của Server 504 có một cửa sổ Pet Training vào thứ Sáu **12:00–15:59 server time** cho các Pet resources nêu trên.

Đây là **Server 504 operational schedule**, không phải universal game rule. Event rotation có thể thay đổi.

## Community resource label

Các guide gần đây cũng dùng các tên generic như:

- Pet Feed / Tactical Rations;
- Advanced Training Manual;
- Pet breakthrough materials;
- Medals of Honor.

Các tên từ guide/localization khác không được mặc định map 1:1 với inventory label hiện tại của Server 504 nếu chưa có screenshot.

## Chính sách inventory đề xuất

Với mỗi Pet material, về sau nên lưu:

| Field | Ý nghĩa |
| --- | --- |
| exact in-game name | tránh nhầm localization |
| icon screenshot | xác minh nhanh nhất |
| primary function | level / breakthrough / training / potential / rescue |
| source | event, shop, dispatch, package, v.v. |
| Alliance Duel points | double-dip planning |
| Survival Preparedness points | double-dip planning |

## Quy tắc tiêu tài nguyên

Trừ khi một Agent unlock hoặc combat breakpoint tức thời quan trọng hơn, ưu tiên tiêu Pet resources khi chúng ghi điểm trong **hai hệ thống cùng lúc**.
